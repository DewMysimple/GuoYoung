# ADR-017 采用唯一记忆根、五页当前状态与单一日志索引

## 背景

旧启动读取约 3.6 万 Unicode 字符，其中当前状态页超过 3 万字符，混合了当前事实、旧机器目录与逐版本验证。总日志表与六分类表重复维护，199 篇历史日志采用无 frontmatter 编号格式。用户于 2026-10-30 明确要求依当前 wiki-memory Skill 改善本工程记忆架构。

## 决策

由 Agent 在本次授权范围内选择 standard（schema 2，工具基线 3.2.1），将 Wiki 迁到根目录唯一的 `wiki_memory/`。README 是唯一全局导航，根 AGENTS 保留工程执行契约，记忆 AGENTS 只维护记忆协议。

当前事实拆为项目概览、系统架构、当前约束、当前待办、已知问题五页；专题保留中文名称、移入知识目录。旧长状态页封存为 archived 快照，不能作为当前基线。新页保留来源和核实范围，测试结果区分历史与当前工作区。

六类目录、独立编号、八字段五章节及无 frontmatter 日志格式继续遵循本工程契约。项目工具副本用只读适配层提取旧日志元数据，映射旧 ADR/主题类型，不批量重写封存正文。仅总日志 MOC 生成一次登记；旧分类索引字段改指总 MOC，对应六个子 MOC 合并移除。ADR-012 的分层和六分类仍沿用，入口与双重登记由本决定替代。

## 理由、代价与实施

五页分开保存恢复信息，使启动只需概览、约束、待办，专题和日志按需加载。自动区索引减少事实和登记漂移；项目副本使后续维护不依赖个人 Skill 目录。保留格式适配是相对通用工具的定制，升级需先比较，不能直接覆盖。长专题仍可能触发单页预算提示，本轮不为清零警告重写历史或整体拆分。

迁移只改日志/旧 ADR 的内部引用路径，旧日期、命令、结论、测试失败均保留；旧 ADR-012 只改替代元数据并互链。工具测试、历史内容保全、五页语义和严格检查为验收依据，实际结果见本轮日志。
