# ADR-018 卡片与浮窗采用独立参数及分层磨砂绘制

## 背景

卡片、Dialog、菜单和Popup共用blur，卡片完全透明且不磨砂时浮层失去隔离。菜单即使配置30px，也受父Dialog的Backdrop Root限制，不能柔化同一父级内容中的文字。设置抽屉另读取sidebar参数，公共菜单固定高度还会被内部滚动区裁剪。起点真实浏览器证据见外观专题与本轮交付资料。

## 决策

用户要求卡片与浮窗独立调节；Agent在该授权范围内选择以下实现。

- 原卡片透明度和0–30px磨砂含义保留；新增overlay透明度、磨砂、遮罩和可读性保护。唯一派生入口是wallpaperGlassStyle，主应用、body Portal、工具栏Popup与设置预览共用输出，不新增偏好存储。
- Dialog、确认框、设置和Popup主壳由背后的同胞伪元素绘制一层背景磨砂，内容宿主保持透明且无滤镜。内部菜单保留在原Radix焦点范围内，独立采样其下方文字；不以整壳opacity或前景blur模拟磨砂。
- popover使用更强填色保护；nested/control只提供内层色调，不重复背景磨砂。持久顶栏和分组导航保留自身材质与既有作用域。具体默认值、保护公式和语义表只在外观专题维护。
- 本地菜单按真实视口与滚动/裁剪祖先测量可用空间，自动翻转并内部滚动；保留原键盘、Escape和焦点合同。
- state v30经原存储边界只补新字段，旧卡片值与完整旧自定义槽保留。无壁纸主壳用主题实色，减少透明度或不支持滤镜走独立降级。

## 理由与代价

同胞绘制层避免内容宿主成为嵌套Backdrop Root，无需将所有菜单迁出Dialog或建立第二套焦点系统。隔离仅用于绘制层排序，不能在内容链中叠加新的filter、opacity或mask。Popup只能磨砂自身画布，无法采样浏览器页面。

静态守卫检查浮层误用卡片token、固定实底、重复偏好源和前景模糊，不能替代真实像素与Portal巡检。迁移、极端壁纸、0/高磨砂对照、菜单限高、降级和完整回归构成验收；所有结论以本轮最终报告为准，阶段失败保留。
