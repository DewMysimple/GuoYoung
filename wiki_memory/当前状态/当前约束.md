# 当前约束

## 用户要求与技术约束

根 [AGENTS.md](../../AGENTS.md) 是工程执行契约；本页提供按需定位，约束变更先同步原契约。

- 用户范围：桌面网页和桌面扩展；现有移动回归按原命令保留，不主动新增手机适配/专项验收。
- 排序位移只由 dnd-kit 控制；Motion 不叠加 transform，`framer-motion` 和 override 的 `motion-dom` 固定 12.23.12（`package.json`）。
- `site-hub:v1` 不变；新增持久字段写迁移，只补不覆盖有效旧值（`src/lib/storage.ts`）。拖拽操作先读 [[知识/拖拽交互契约|专属契约]]。
- 渐进维护由问题和收益驱动；完整 backlog 见 [[知识/工程维护清单|维护清单]]，不批量升级依赖或因文件大整体重构。

## 兼容性与操作边界

用户要求实现/修复/维护即在任务范围内执行，不需固定口令。Windows 用 npm.cmd；业务变更依根契约完成类型、单元、完整 E2E、双构建、真实浏览器与记忆检查。扩展运行代码/资源/manifest 改动才递增版本、打包并覆盖固定安装目录，保留旧资源；浏览器负责重载，不操作扩展管理页。

本项目文件修改后必须本地 commit 并推送当前分支至 origin；先核对实际 upstream 并保全他人改动。日志只保留事件、知识可修订；本次迁移采用 [[决策/ADR-017|ADR-017]] 的唯一记忆根与单一日志索引，沿用无 frontmatter 编号日志。构建、依赖、报告与本地诊断产物不提交。
