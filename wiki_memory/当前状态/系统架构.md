# 系统架构

## 模块职责与边界

主页面由 `src/App.tsx` 编排收藏、GitHub、历史、设置和拖拽；界面组件在 `src/components/`，状态编排在 `src/hooks/`，业务与平台适配在 `src/lib/`。`use-site-hub.ts` 是持久收藏入口，`site-state.ts` 做业务变换，`state-store.ts` 适配读写，`storage.ts` 负责兼容解析与迁移；不增加第二个全局状态源。

第一阶段URL规则归collection/model/site-url；第二阶段两项分组重排归groups/model/group-reorder，site-utils保留兼容出口、useSiteHub直连；GitHub来源去重、报告排序与摘要归github/model/repository-refresh。第三阶段应用层app/hooks/use-github-repository-workflow拥有读取/预览/确认/串行刷新/报告的8个临时状态与7个动作，仍调用纯模型和原主状态命令；use-collection-search-session拥有3个搜索状态及起点ref，同事件协调恢复、历史键盘/提交及独立错误。App保留唯一useSiteHub、当前组选取、导航、投影/排序、选择/拖拽、原Dialog/搜索JSX和根外观生命周期。精确API、指标、过渡类型引用和下阶段前置接口仅在 [[知识/业务模块边界与架构基线|业务模块边界与架构基线]] 维护。守卫只登记两个精确assembly路径，不增加公共许可。

第四阶段将 styles.css 连续后缀归 styles/late-overrides.css。storage-normalization 负责品牌和壁纸规范化，storage 保留原具名入口与迁移。第四阶段的初始浮窗会话归属见 [[知识/业务模块边界与架构基线|架构基线]]。

1.2.64 的 `PopupApp` 装配工具栏快速收藏、原生书签浏览与显式分组复制。`BookmarkDataWorkspace` 在新标签数据页负责目录映射预览与原生删除确认。两端共用 `bookmark-manager.ts`，数据页导入经过 `useSiteHub` 保存回执。`glass-material.css` 在主页根节点及工具栏入口派生材质，公共控件同时覆盖 `body` 下的弹层。

卡片尺寸专项保持既有lib与组件边界：唯一模型→同Context/单RO→互斥轨道CSS，App提供根fallback、square网格与两拖动预览复用内容令牌。新增4条窄组件依赖后图128/331/127、双循环/违规/未解析均0；产品规则只在[[知识/外观与设置体系|外观与设置契约]]维护，交付见[[日志/Bug处理/第058次|卡片尺寸专项交付]]。

扩展 popup 共用业务和存储，`src/background.ts` 只桥接历史变更事件；浏览历史直接读浏览器 API。完整模块定位见 [[知识/系统架构详解|系统架构详解]]，拖拽修改先读 [[知识/拖拽交互契约|拖拽交互契约]]。

## 数据流与依赖

界面命令 → useSiteHub → 纯业务变换 → 存储适配 → 订阅回馈。网页用 localStorage，扩展用 chrome.storage.local。固定 `site-hub:v1`，默认与迁移目标 state **v29**（`src/data/defaults.ts`、`src/lib/storage.ts`）。`group-hierarchy.ts` 负责二级关系、计数和混合顺序。选择、拖拽会话和未保存设置草稿为临时状态。壁纸/字体 Blob 在 IndexedDB `site-hub-assets` v2 的独立 stores，state 保留引用（`asset-store.ts`）。

React/TypeScript/Vite/Tailwind 构成应用；dnd-kit 控制排序，Motion 固定版本。GitHub 公开 API 和浏览器 API 是外部依赖；history 为可选权限，见 `public/manifest.json`、`src/lib/github-repository-api.ts`。

## 运行与部署

`npm.cmd ci` 安装锁定依赖，`npm.cmd run dev` 默认 5173。`build` 生成 `dist/`；`build:extension` 生成 `dist-extension/`，由 Vite mode 分流，未维护两套产品源码。Node 支持范围由 `package.json` 的 engines 决定；Windows 使用 npm.cmd。扩展交付遵循 [[知识/扩展与构建交付|扩展与构建交付]]，运行时代码提取触发版本递增及打包。
