# Mysimple 工程记忆

这是工程记忆的唯一导航与使用说明。维护规则见 [AGENTS.md](AGENTS.md)，工程执行规则见 [根协作契约](../AGENTS.md)。

模式为 **standard**（schema 2，工具基线 3.2.1）。2026-10-30 由 Agent 在用户明确授权改善记忆架构的范围内选择：主页面、MV3 popup、后台事件桥共用数据而有不同运行边界，原状态页超过三万字符，需分开保存状态、约束与恢复位置。原有日志、主题与决策保留；迁移选择及兼容差异见 [[决策/ADR-017|ADR-017]]。

新会话读根协作契约、本协议和本页，再读项目概览、当前约束、当前待办；系统架构、已知问题与专题按任务加载。同一上下文已读且未变化的内容直接复用。日常开发直接依项目协议维护，不调用个人 Skill。

先在下面定位当前状态，再按主题查知识或决策；需要历史来由才查日志。长专题用 `rg -n '关键词' wiki_memory/知识` 定位后分段读，日志用 `rg -n '关键词' wiki_memory/日志`，不默认通读索引或全部历史。编辑日期不表示整页已重新核实；历史验证不能外推到当前分支。
