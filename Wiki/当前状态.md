## 产品与协作

- 对外名称：**Mysimple · 网站收藏**。同一 React 源码交付网页与 Chrome / Edge MV3 新标签页扩展，无账号与自建后端。
- Git 远程：`origin` → [DewMysimple/GuoYoung](https://github.com/DewMysimple/GuoYoung.git)。文件修改经验证后由 Agent 提交并推送当前分支；发布标签按具体任务执行。
- 用户明确要求实现、修复或维护，即在任务范围内执行；复杂任务说明安排并持续汇报，**不要求固定口令或再次确认计划**。ADR-011 已由 [[Wiki/决策/ADR-013|ADR-013]] 取代。
- 新会话先读 AGENTS、本页与 MOC，按任务读主题页；本期评估和优先级见 [[Wiki/工程维护清单|工程维护清单]]。

## 兼容与交付基线

- 收藏 state **v15**；存储键恒为 `site-hub:v1`。网页用 localStorage，扩展用 chrome.storage.local，本地壁纸在 IndexedDB；迁移只补不覆盖，v14→v15 移除已废弃的主题字段。
- `public/manifest.json` 为扩展版本真源，当前 **1.1.76**；`package.json` 的 1.0.0 独立于产品扩展版本。
- 最新 GitHub Release 为 [`v1.1.76`](https://github.com/DewMysimple/GuoYoung/releases/tag/v1.1.76)，资产为 `site-hub-extension.zip`。
- 网页输出 `dist/`，扩展输出 `dist-extension/`；固定解压交付目录与 ZIP 位于 artifacts 根，截图按扩展版本归档，临时诊断在 artifacts/working。
- 普通提交 / PR 使用 Validate project 工作流验证；版本标签继续触发 Publish extension release 工作流，二者使用 Node 24。

## 当前验证

本期验证于 2026-09-16 完成；详细结果见 [[Wiki/测试与验证基线|测试与验证基线]] 和 [[Wiki/日志/功能添加/第034次|本期功能日志]]。

- 单元与组件：20 文件、198 例通过；独立服务器 E2E：110 passed / 36 skipped / 0 failed。
- “全部－按分组显示”中，多选按钮进入卡片模式后显示当前组的“全选/取消全选”；点击分组标题可直接切换到小组多选，分组模式点击卡片或组内全选可直接切回卡片多选。
- 顶部品牌点击已改为无导航按钮：回到收藏主页但保持当前 URL，不再触发站点根路径空白页。
- 网页 / 扩展生产构建、固定浅色的生产 Chrome 巡检和 Wiki 校验完成；设置侧栏的窄窗口导航问题见下方待办。
- 本期发现旧 E2E 的两个分组排序用例在视口外发起鼠标动作；修正为先滚入视口，并增加激活与刷新后持久化校验。原先的“既有时序问题”判断已更正，不作为可接受失败基线。
- 实际 Chrome / Edge 扩展安装中的权限提示、原生事件同步仍需与网页模拟测试区分；不能以模拟 API 通过代替实机扩展验收。

## 正在跟踪

1. **开发依赖升级**：nanoid 已补丁更新；Vitest / @vitest/mocker 仍有同一安全公告关联的 2 项 moderate 审计记录，需专项大版本升级，详见维护清单。
2. **代码体积与维护成本**：App、全局 CSS、设置 / 历史组件及单个 E2E 文件较大，随相关功能逐步拆分；暂不整体重构。
3. **E2E 并发**：保留 fullyParallel 能力，完整验收与 CI 使用 1 worker，避免已知资源竞争；移动端部分测试为桌面专用场景而明确跳过。
4. **交互边界**：继续关注密集网格、偏心抓取、复杂缩放；拖拽活动中取证使用视口截图，避免全页截图干扰滚动与落点。
5. **浏览器限制**：原生新标签搜索框不可嵌入、无痕新标签不接管、工具栏固定需手动；Chrome / Edge 历史按配置文件独立，删除粒度为 URL 而不是单次 visit。
6. **窄窗口设置导航**：约 920px 窗口打开设置侧栏后，剩余主区域的顶部导航文字会挤成竖排；本期记录为 P2 布局待办，未改动产品样式。
7. **本地数据与网络边界**：无跨设备自动同步；图标、在线图片、搜索和 GitHub 导入需要网络。备份不包含回收站、搜索 / 浏览器历史及本地壁纸文件。
