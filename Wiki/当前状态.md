# 当前状态

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 本页快照工程"现在能做什么、验证到什么程度、还剩什么坑"。与源码冲突时以代码为准并当轮修正。

## 已实现能力

- 网站收藏工作台：增删改、搜索、分组（SiteGroup）、拖拽排序、图标、壁纸、搜索历史、设置面板与链接回收站（state 演进至 v14）；支持按工作区持久化排列方式、持久化点击次数与“热量排列”，热量排列时卡片在网址下方、组名上方显示纯数字点击次数。
- 双形态交付：网页版 `dist/` 与 MV3 扩展版 `dist-extension/`（接管浏览器新标签页）。
- 本地验收资料：扩展目录与 ZIP 固定保留在 `artifacts/` 根目录；截图/录屏按扩展版本归入 `artifacts/releases/`，原始录屏与日志归入 `artifacts/working/`。
- 图标：七级回退链 + 64px 高清门槛 + 占位图指纹校验；每站点图标来源选择。
- 拖拽：50px 阈值 + 冻结槽位 + 18px 滞回；手动排列由 dnd-kit 实时交叠面积控制插槽和跨组占位，松手只提交当前虚线框对应的 `SiteDropIntent`，没有有效目标框就保持原位；名称/时间排序使用仅迁移模式，可拖到分组行或顶部标签：从具体分组页发起时，标签悬停 450ms 会在松手前预览目标分组，且同一次拖拽可继续改向或拖回原分组，松手后才按最终目标完成迁移；从“全部”发起时保留“全部”视图，同组释放为无操作。
- 分组与批量迁移：普通分组可在顶部标签横向拖动或在“全部－按分组显示”中纵向拖动；分组排序采用完整区域边界命中，越界后由 dnd-kit 立即推演相邻分组与虚线来源槽的让位位置，松手才持久化，反向拖回或取消会复原，标签自动滚动期间继续实时演算；分组标题只接受鼠标/触屏排序，不响应 Space/Enter 键盘激活，标题主交互区同时禁止文本选择，避免指针经过名称时出现 I-beam。“全部－按分组显示”还支持非连续多选普通分组并作为稳定顺序块移动，“其他”不可选且固定末尾。分组标题单击按既有待选择规则工作，双击普通分组标题可直接选中该组并进入小组多选；分组标题最右侧保留网站多选入口：首次点击后按钮变为“选择”并进入待选择状态，点击标题进入分组选择、点击卡片进入链接选择；主页卡片和分组标题支持 Windows 原生 Shift 范围选择，以首次点击项为锚点并选中首尾之间的连续项；进入小组多选后卡片链接不可打开，已进入一种模式后只能用“切换”按钮进入另一种待选择状态，空白、Esc 或清空最后一项会退出；选择圆圈固定在卡片右下角。
- 分组管理：顶部分组标签支持 450ms 长按定向管理，移动超过 8px 后由拖动意图接管并关闭管理器；“按分组显示”的标题三点按钮可直接管理对应分组。管理/新建/作者仓库导入弹窗使用透明遮罩与固定、四角完整的圆角外壳，外层不滚动，内容区独立滚动；提供 48 个图标（桌面 6 列，编辑区内容过长时独立滚动；移动端 4 列），删除入口位于当前分组摘要行；普通分组直接在该入口 2 秒内点击两次删除，不再打开二级确认弹窗，非空组内链接统一进入回收站，受保护的“其他”保持只读。管理器左侧拖动进入首/末行中点走廊或越过列表边界就立即推演首尾分组，并由 rAF 按边缘深度滚动列表；管理器拖动浮层通过 portal 脱离弹窗裁剪，右侧编辑区不作为排序落点；拖动手柄声明 `touch-action: none`，避免移动端原生滚动抢占 PointerSensor；窗口失焦、页面隐藏、离开浏览器视口或 pointercancel 时立即取消，避免跨程序后浮层残留。任何单侧圆角、直角、滚动条贴边截断或外壳被子元素覆盖都视为 UI 回归。
- 分组资源包：管理分组右侧摘要区提供“导入资源/导出资源”，资源包只携带当前组名称、图标和网站便携字段，不包含整库设置、搜索历史、回收站或本机 ID；导入追加到选中目标组，规范化 URL 全局去重，目标组名称和图标保持不变。管理器列表拖动使用独立紧凑 DragOverlay 与透明源位占位，避免活动行和相邻让位行重叠；窗口失焦、页面隐藏、pagehide 或 pointercancel 时立即卸载拖动上下文，避免跨程序后浮层残留。右侧摘要操作收束为单行导入/导出/删除工具栏，短标签配合完整 aria-label，避免操作换行。
- 添加、删除与回收站：主页右上角统一“添加”菜单可选择添加网站或新建分组；“全部－按分组显示”的每个分组标题左侧边界外提供仅含“+”的圆形插入入口。桌面仅在紧凑标题区、加号自身命中区、键盘焦点或菜单展开时揭示，经过整行空白和右侧网站多选按钮不会显示；链接拖放的整行空白命中范围保持不变。网站删除与回收站永久删除使用 2 秒内二次点击确认。设置－数据可恢复、全部恢复、逐项永久删除或清空链接回收站，并可选择 7/30/90 天或永不自动清理；默认保留 30 天。所有临时操作消息 5 秒后关闭。
- 设置侧栏：点击侧栏外区域时，干净草稿直接关闭；有未保存修改则先询问继续编辑或放弃并恢复已保存设置。壁纸“在页面拖动调整”期间停用外部关闭层，保证页面手势继续用于位置和缩放调整。
- 扩展 popup：双页签 + 书签导入。
- 工程记忆 Wiki 本身：110 篇日志 + 知识层 + 12 篇 ADR + `npm run lint:wiki` 校验。

- 回收站快捷入口：设置按钮左侧新增同风格回收站图标，点击直接打开“设置－数据－链接回收站”并展开内容；拖拽期间普通卡片的 hover/focus 反馈保持中性，真实落点只显示低对比度虚线框，不再呈现相邻卡片实线蓝色选中态。
- 浏览器历史记录：扩展版顶栏依次提供“收藏主页”和“历史记录”入口，在同一新标签页切换到独立历史视图；通过可选 `history` 权限读取当前 Chrome / Edge 配置文件历史，按主域名聚合为复用收藏主页 `site-card` 几何与内容结构的长方形站点卡片，历史页搜索框置顶并与收藏主页保持同一高度，移除大标题区，数量统计并入筛选工具栏；时间范围默认“近 7 天”，选择器为较紧凑的中等圆角控件，左侧复用顶栏历史记录图标，整颗控件可点击并用自绘圆角菜单替代原生方形下拉层；标签字号提升并对中文选项文字启用更清晰的字重、字距和抗锯齿设置；默认不显示选择控件；历史搜索复用收藏主页的 `workspace-intro` / `search-panel` / `search-input` 位置和样式。点击站点卡片进入独立历史详情子页面，不在卡片内部展开，也不显示展开箭头；点击历史页“多选”进入选择模式后，才在卡片右下角显示与收藏主页 `SiteCard` 一致的圆形选择控件，支持整卡选择、站点级全选与部分选中，站点卡片和详情 URL 卡片也支持 Windows 原生 Shift 首尾范围选择，Esc 退出选择；进入详情回到顶部，页面内“返回历史记录”和浏览器原生后退都能逐层回到列表并恢复滚动位置；设置、分组管理、添加/编辑和 GitHub 导入面板标题栏提供明确“返回”入口；保留全部、今天、昨天、近 7 天、近 30 天、标题/URL 搜索、单条删除和勾选批量删除，不提供清空全部或范围清理入口；每条历史链接都以新标签页打开。权限和历史方法同时兼容 Promise/callback API，授权失败显示可重试错误，读取失败提供重新读取入口；浏览器原生历史变更由 MV3 service worker 与历史页事件订阅静默刷新，重新获得焦点或页面可见时主动补查；网页构建保留入口并说明仅扩展版可用，不改变收藏 state。
- GitHub 独立工作区：顶栏顺序为“收藏主页 → GitHub → 历史记录”；state v11 为分组增加 `main` / `github` 工作区，v12 再为两个工作区分别保存 `displayModeByWorkspace`，预置“仓库、工具、文档、其他”四组，复用收藏的搜索、排序、拖拽、删除、回收站和分组管理能力。精确识别 `github.com` 及其子域名（不匹配 `github.io` 和相似域名），新增、编辑、拖入与导入按工作区分流；`https://github.com/` 保留为主收藏中的单条共享数据，并在 GitHub 页搜索框下显示固定官方入口，整卡区域沿用收藏卡片的 hover/focus 上移反馈并可在新标签页打开，悬停不额外叠加高亮；右侧提供蓝底白色图标的“刷新仓库”按钮，单击一次会刷新全部已导入且去重后的作者分组，成功结果只追加新仓库；刷新完成后弹出详情窗口，按作者列出新增仓库、跳过项和失败原因；入口菜单只保留“编辑官方入口”和“删除官方入口”，使用不透底的实体弹层，不再显示“放回收藏主页”或一次性迁移撤销项；入口卡片与下方分组工具栏之间不再绘制全宽分隔线。首次进入自动把既有具体 GitHub 链接移动到“其他”，旧 `githubMigration` 记录仍兼容读取但不再暴露撤销操作。
- 跨工作区搜索与作者仓库导入：收藏主页、GitHub 页面及任意具体分组输入搜索词时，都同时查找主收藏和 GitHub 工作区的全部活动收藏，结果统一平铺并标出来源；清空关键词后恢复开始搜索前的工作区和分组，搜索期间禁止拖拽，回收站不参与。浏览器历史页面保持独立搜索边界。GitHub 页面可输入严格格式的作者/组织主页，调用公开 REST API 串行读取全部分页仓库，预览后默认全选确认；活动收藏和回收站 URL 全局跳过，作者分组按来源复用或加后缀创建，来源信息支持手动只追加刷新，也支持从顶部官方入口一次刷新全部作者分组；任意分页失败保持对应来源数据不变，部分来源成功时只提交成功来源。

## 当前限制与遗留问题（8 项）

1. **移动端 E2E 并发超时线索**：`playwright.config` 设 `fullyParallel: true`，移动端 E2E 有并发超时历史；本轮完整实跑未复现，仍需持续观察。
2. 原生新标签页搜索框不可嵌入（浏览器平台限制）。
3. 无痕窗口不接管新标签页（平台限制）。
4. 扩展无法自行固定到工具栏（平台限制）。
5. 拖拽在极端密集网格与复杂缩放下仍值得持续观察；1.1.6 已改为实时卡片交叠面积并保留 18px 滞回。
6. 浏览器历史是敏感权限，首次使用会出现“读取和更改浏览历史”授权提示；拒绝后需要从历史页重新授权。
7. Chrome 与 Edge 的历史记录按浏览器配置文件独立，不能在 Mysimple 中合并；无痕窗口历史不纳入本功能。
8. 浏览器公开历史 API 的删除粒度为 URL、时间范围或全部历史，无法稳定删除单次 visitId；历史列表因此按 URL 汇总展示。
