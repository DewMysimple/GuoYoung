# 当前状态

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 本页快照工程"现在能做什么、验证到什么程度、还剩什么坑"。与源码冲突时以代码为准并当轮修正。

## 已实现能力

- 网站收藏工作台：增删改、搜索、分组（SiteGroup）、拖拽排序、图标、壁纸、搜索历史、设置面板（state 演进至 v8）。
- 双形态交付：网页版 `dist/` 与 MV3 扩展版 `dist-extension/`（接管浏览器新标签页）。
- 本地验收资料：扩展目录与 ZIP 固定保留在 `artifacts/` 根目录；截图/录屏按扩展版本归入 `artifacts/releases/`，原始录屏与日志归入 `artifacts/working/`。
- 图标：七级回退链 + 64px 高清门槛 + 占位图指纹校验；每站点图标来源选择。
- 拖拽：50px 阈值 + 冻结槽位 + 18px 滞回；手动排列由 dnd-kit 实时交叠面积控制插槽和跨组占位，松手只提交当前虚线框对应的 `SiteDropIntent`，没有有效目标框就保持原位；名称/时间排序使用仅迁移模式，可拖到分组行或顶部标签：从具体分组页发起时，标签悬停 450ms 会在松手前预览目标分组，且同一次拖拽可继续改向或拖回原分组，松手后才按最终目标完成迁移；从“全部”发起时保留“全部”视图，同组释放为无操作。
- 分组与批量迁移：普通分组可在顶部标签横向拖动或在“全部－按分组显示”中纵向拖动；分组排序采用完整区域边界命中，越界后由 dnd-kit 立即推演相邻分组与虚线来源槽的让位位置，松手才持久化，反向拖回或取消会复原，标签自动滚动期间继续实时演算；分组标题只接受鼠标/触屏排序，不响应 Space/Enter 键盘激活。多选模式支持从“全部”或具体分组批量跨组迁移，选择圆圈固定在卡片右下角，“其他”继续固定末尾。
- 分组管理：顶部分组标签支持 450ms 长按定向管理，移动超过 8px 后由拖动意图接管并关闭管理器；“按分组显示”的标题三点按钮可直接管理对应分组。管理/新建弹窗使用透明遮罩与固定圆角外壳，桌面端完整展示 24 个图标，删除入口位于当前分组摘要行；删除普通分组可选择迁移网站到“其他”或连同网站删除，受保护的“其他”保持只读。
- 添加与删除：主页右上角统一“添加”菜单可选择添加网站或新建分组；“全部－按分组显示”的每个分组标题左侧边界外提供仅含“+”的圆形插入入口，不再占据标题布局或挤动分组图标，桌面指针直接进入按钮自身的外侧命中区即可揭示，无需先经过分组标题，触屏则常驻；并可选择在当前组前后插入（“其他”只允许前插）。网站卡片与分组最终删除方案都使用 2 秒内二次点击确认，切换目标、点击别处、Esc、拖拽、切页或超时会取消。所有 Dialog/AlertDialog 遮罩均透明且无模糊，继续保持模态阻止背景误操作。
- 设置侧栏：点击侧栏外区域时，干净草稿直接关闭；有未保存修改则先询问继续编辑或放弃并恢复已保存设置。壁纸“在页面拖动调整”期间停用外部关闭层，保证页面手势继续用于位置和缩放调整。
- 扩展 popup：双页签 + 书签导入。
- 工程记忆 Wiki 本身：52 篇日志 + 知识层 + 12 篇 ADR + `npm run lint:wiki` 校验。

## 当前验证基线

- 单元：`npm test`（vitest），15 个测试文件、115 例全部通过；口径见 [[Wiki/测试与验证基线|测试与验证基线]]。
- E2E：`npm run test:e2e`（Playwright），48 条 test × 2 project（chromium + Pixel 7 移动端），本轮实跑 70 passed / 26 skipped；新增覆盖鼠标从页面空白处直接进入隐藏“+”的命中区并立即揭示入口。
- 扩展版本：`public/manifest.json` 为 1.1.20；完成当轮构建后 `dist/manifest.json` 与 `dist-extension/manifest.json` 同步为 1.1.20；网页包版本 `package.json` 仍独立使用 1.0.0。

## 当前限制与遗留问题（6 项）

1. **移动端 E2E 并发超时线索**：`playwright.config` 设 `fullyParallel: true`，移动端 E2E 有并发超时历史；本轮完整实跑未复现，仍需持续观察。
2. 发版全手工：扩展改动出 ZIP + 递增版本，无 CI。
3. 原生新标签页搜索框不可嵌入（浏览器平台限制）。
4. 无痕窗口不接管新标签页（平台限制）。
5. 扩展无法自行固定到工具栏（平台限制）。
6. 拖拽在极端密集网格与复杂缩放下仍值得持续观察；1.1.6 已改为实时卡片交叠面积并保留 18px 滞回。

## 下一步

- 评估移动端 E2E 是否需关闭 `fullyParallel` 或加超时。
- 为扩展版本递增、构建、ZIP 与浏览器验收建立自动化发布检查。
- 继续用偏心抓取、跨行与复杂缩放场景观察 18px 滞回手感。
