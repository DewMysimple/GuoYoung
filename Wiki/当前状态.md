## 产品与协作

- 对外名称：**Mysimple · 网站收藏**。同一 React 源码交付网页与 Chrome / Edge MV3 新标签页扩展，无账号与自建后端。
- Git 远程：`origin` → [DewMysimple/GuoYoung](https://github.com/DewMysimple/GuoYoung.git)。文件修改经验证后由 Agent 提交并推送当前分支；发布标签按具体任务执行。
- 用户明确要求实现、修复或维护，即在任务范围内执行；复杂任务说明安排并持续汇报，**不要求固定口令或再次确认计划**。ADR-011 已由 [[Wiki/决策/ADR-013|ADR-013]] 取代。
- 新会话先读 AGENTS、本页与 MOC，按任务读主题页；本期评估和优先级见 [[Wiki/工程维护清单|工程维护清单]]。

## 兼容与交付基线

- 收藏 state **v15**；存储键恒为 `site-hub:v1`。网页用 localStorage，扩展用 chrome.storage.local，本地壁纸在 IndexedDB；迁移只补不覆盖，v14→v15 移除已废弃的主题字段。
- `public/manifest.json` 为扩展版本真源，当前 **1.1.80**；`package.json` 的 1.0.0 独立于产品扩展版本。
- 上次已记录的 GitHub Release 为 [`v1.1.76`](https://github.com/DewMysimple/GuoYoung/releases/tag/v1.1.76)，资产为 `site-hub-extension.zip`；本轮本地交付 1.1.80，仅推送代码分支，未创建新的发布标签。
- 网页输出 `dist/`，扩展输出 `dist-extension/`；固定解压交付目录与 ZIP 位于 artifacts 根，截图按扩展版本归档，临时诊断在 artifacts/working。
- 普通提交 / PR 使用 Validate project 工作流验证；版本标签继续触发 Publish extension release 工作流，二者使用 Node 24。

## 当前验证

本期验证于 2026-09-20 完成；详细结果见 [[Wiki/测试与验证基线|测试与验证基线]] 和 [[Wiki/日志/功能添加/第038次|本期设置与公共模块日志]]。

- 单元与组件：32 文件、271 例通过；完整 E2E：128 passed / 38 skipped / 0 failed，83 个逻辑场景在两个 project 执行。
- 设置提供五项布局微调、恢复默认/上次预设、顶栏参数与实时拖动；侧栏左边界去除阴影，两个尺寸手柄共用取消、键盘与提交逻辑。壁纸与数据编辑各自归入受控组件。
- 收藏主页、GitHub、浏览历史共用真实搜索组件、卡片内容/选择/打开组件；历史读取、权限、刷新、异步过期保护与删除归入独立 hook，搜索数据边界保持。state v15、原字段及依赖保持。
- 壁纸下保留原外形，导航仅轻微透底；管理入口使用完整圆角按钮，保存提示使用无文字阴影的小标签，标题和分组区不加整条白底。
- 网页/扩展生产构建、1.1.80 ZIP、真实 Chrome 截图与 Wiki 校验完成；360/390/920/1440px 设置、原图壁纸、平铺/分组、GitHub 与历史总览/详情均检查，无横向溢出及未捕获页面异常。
- 浏览器历史 E2E 和截图使用模拟 API；本轮未重做所有原生权限交互。构建大 chunk 告警保留，未以调整阈值消除提示。

## 正在跟踪

1. **拖拽与大型组件**：App 的网站拖拽 DOM/rAF、几何测量仍较集中；设置编辑与历史数据/卡片已拆分，壁纸定位手势和历史选择/导航仍按自然边界渐进维护，完整顺序见 [[Wiki/工程维护清单|工程维护清单]]。
2. **全局样式与包体积**：失效 CSS 已清理，剩余有效样式仍需随需求分域；大 chunk 告警保留，先测量再决定拆包。
3. **开发依赖**：1.1.78 体检时的官方 registry 审计有 Vitest / @vitest/mocker 两项 moderate 开发依赖记录，需独立大版本升级；生产依赖未检出审计项，Motion 锁版保持不变。
4. **测试设备边界**：完整验收与 CI 使用 1 worker；38 个设备范围跳过不计为通过。密集网格、复杂缩放、偏心抓取仍需持续截图验证。
5. **数据与浏览器边界**：无跨设备自动同步；popup 写前重读不是原子事务，真正并发写入仍需专项处理。原生搜索框不可嵌入，无痕新标签不接管，工具栏固定需手动；历史按浏览器配置文件独立且 URL 级删除。
6. **图片与导出**：取消旧图片任务会阻止草稿回写，未增加历史图片垃圾回收；备份不包含回收站、搜索/浏览器历史和本地壁纸文件。
