## 产品与协作

- 对外名称：**Mysimple · 网站收藏**。同一 React 源码交付网页与 Chrome / Edge MV3 新标签页扩展，无账号与自建后端。
- Git 远程：`origin` → [DewMysimple/GuoYoung](https://github.com/DewMysimple/GuoYoung.git)。文件修改经验证后由 Agent 提交并推送当前分支；发布标签按具体任务执行。
- 用户明确要求实现、修复或维护，即在任务范围内执行；复杂任务说明安排并持续汇报，**不要求固定口令或再次确认计划**。ADR-011 已由 [[Wiki/决策/ADR-013|ADR-013]] 取代。
- 新会话先读 AGENTS、本页与 MOC，按任务读主题页；本期评估和优先级见 [[Wiki/工程维护清单|工程维护清单]]。

## 兼容与交付基线

- 收藏 state **v16**；存储键恒为 `site-hub:v1`。网页用 localStorage，扩展用 chrome.storage.local，本地壁纸在 IndexedDB；迁移只补不覆盖，v16 新增 appearance.theme，旧安装缺失时保留浅色，新安装默认跟随系统。
- `public/manifest.json` 为扩展版本真源，当前 **1.1.85**；`package.json` 的 1.0.0 独立于产品扩展版本。
- 上次已记录的 GitHub Release 为 [`v1.1.76`](https://github.com/DewMysimple/GuoYoung/releases/tag/v1.1.76)，资产为 `site-hub-extension.zip`；本轮本地交付 1.1.85，仅推送代码分支，未创建新的发布标签。
- 网页输出 `dist/`，扩展输出 `dist-extension/`；固定解压交付目录与 ZIP 位于 artifacts 根，截图按扩展版本归档，临时诊断在 artifacts/working。
- 普通提交 / PR 使用 Validate project 工作流验证；版本标签继续触发 Publish extension release 工作流，二者使用 Node 24。

## 当前验证

本期验证于 2026-09-24 完成；详细结果见 [[Wiki/测试与验证基线|测试与验证基线]] 和 [[Wiki/日志/功能添加/第042次|本期交付日志]]。

- 单元与组件：40 文件、309 例通过；完整 E2E：154 passed / 38 skipped / 0 failed，96 个逻辑场景在两个 project 执行。
- 1.1.85 去除设置右上角重复返回；滚动容器预留滚动条位置，根页面对称预留保持搜索居中。分组标题改为左侧名称/数量、右侧统一操作，按钮与拖拽区分离，插入菜单不再承担选择控件职责。
- 分组图标、卡片与页面标题共用左边缘，加号正常浏览时常驻；分组拖动显示名称、数量及网站内容预览。管理分组提供圆圈选择、全选/反选/Shift 范围和确认批量删除，手机概要操作分行防止文字挤压。
- 平铺/单组/分组共用 CollectionSiteGrid；分组展示、标题、插入菜单和 sortable 外壳独立。网站/分组拖拽编排、几何、事件、滚动与误点击有独立边界，最新回调、待激活取消、触屏事件与外部保存失效均验证，见 [[Wiki/收藏分组模块边界|收藏分组模块边界]]。原收藏字段保持；本地拼音词典与 Motion 锁版保持。
- 壁纸下保留原外形，导航仅轻微透底；管理入口使用完整圆角按钮，保存提示使用无文字阴影的小标签，标题和分组区不加整条白底。
- 面板边界手柄悬停、键盘聚焦和拖动时居中展开，移开收回；桌面竖向 54→72px、横向 64→96px，使用主题色。
- 收藏搜索兼容输入法分隔符、拼音全拼、首字母及混合前缀；相关度优先，不改变保存的排序，组合选字期间不触发网页搜索；见 [[Wiki/收藏搜索匹配|收藏搜索匹配]]。
- 网页/扩展生产构建、1.1.85 ZIP 及解压目录逐文件 SHA256 核对完成。360/390/920/1440px 浅深标题、菜单、选择状态、580px 设置折叠/展开、分组拖动开始/让位/落定及刷新、壁纸局部透底和常规 capture 已巡检；未见未捕获页面异常。
- 主题回归覆盖即时预览/取消、保存刷新、固定模式不随系统、system 实时更新、旧数据迁移与 popup 共享偏好；1.1.83 的六种预设强调色深色文字抽样对比度至少 4.5:1，本轮未更改颜色契约。
- 历史监听权限授予/撤销，立即清除失效数据、忽略过期响应并支持重新授权。原生 Chromium 151.0.7922.34 使用独立配置文件实际点击拒绝/允许，通过 125 条合成历史搜索、删除、双页面同步、刷新和浏览器重启验收；真实 Edge 安装与企业策略未实测，callback 兼容由自动化覆盖。构建大 chunk 告警与外部 favicon 回退保留。

## 正在跟踪

1. **拖拽与大型组件**：网站/分组拖拽 DOM/rAF、几何和展示已提取；网站意图分支仍需按具体失败证据渐进处理。设置编辑与历史数据/卡片已拆分，后续为壁纸定位手势和历史选择/导航，完整顺序见 [[Wiki/工程维护清单|工程维护清单]]。
2. **全局样式与包体积**：失效 CSS 已清理，剩余有效样式仍需随需求分域；大 chunk 告警保留，先测量再决定拆包。
3. **开发依赖**：1.1.78 体检时的官方 registry 审计有 Vitest / @vitest/mocker 两项 moderate 开发依赖记录，需独立大版本升级；生产依赖未检出审计项，Motion 锁版保持不变。
4. **测试设备边界**：完整验收与 CI 使用 1 worker；38 个设备范围跳过不计为通过。密集网格、复杂缩放、偏心抓取仍需持续截图验证。
5. **数据与浏览器边界**：无跨设备自动同步；popup 写前重读不是原子事务，真正并发写入仍需专项处理。原生搜索框不可嵌入，无痕新标签不接管，工具栏固定需手动；历史按浏览器配置文件独立且 URL 级删除。
6. **图片与导出**：取消旧图片任务会阻止草稿回写，未增加历史图片垃圾回收；备份不包含回收站、搜索/浏览器历史和本地壁纸文件。
