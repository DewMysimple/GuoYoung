# 当前状态

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 本页快照工程"现在能做什么、验证到什么程度、还剩什么坑"。与源码冲突时以代码为准并当轮修正。

## 已实现能力

- 网站收藏工作台：增删改、搜索、分组（SiteGroup）、拖拽排序、图标、壁纸、搜索历史、设置面板与链接回收站（state 演进至 v9）。
- 双形态交付：网页版 `dist/` 与 MV3 扩展版 `dist-extension/`（接管浏览器新标签页）。
- 本地验收资料：扩展目录与 ZIP 固定保留在 `artifacts/` 根目录；截图/录屏按扩展版本归入 `artifacts/releases/`，原始录屏与日志归入 `artifacts/working/`。
- 图标：七级回退链 + 64px 高清门槛 + 占位图指纹校验；每站点图标来源选择。
- 拖拽：50px 阈值 + 冻结槽位 + 18px 滞回；手动排列由 dnd-kit 实时交叠面积控制插槽和跨组占位，松手只提交当前虚线框对应的 `SiteDropIntent`，没有有效目标框就保持原位；名称/时间排序使用仅迁移模式，可拖到分组行或顶部标签：从具体分组页发起时，标签悬停 450ms 会在松手前预览目标分组，且同一次拖拽可继续改向或拖回原分组，松手后才按最终目标完成迁移；从“全部”发起时保留“全部”视图，同组释放为无操作。
- 分组与批量迁移：普通分组可在顶部标签横向拖动或在“全部－按分组显示”中纵向拖动；分组排序采用完整区域边界命中，越界后由 dnd-kit 立即推演相邻分组与虚线来源槽的让位位置，松手才持久化，反向拖回或取消会复原，标签自动滚动期间继续实时演算；分组标题只接受鼠标/触屏排序，不响应 Space/Enter 键盘激活，标题主交互区同时禁止文本选择，避免指针经过名称时出现 I-beam。“全部－按分组显示”还支持非连续多选普通分组并作为稳定顺序块移动，“其他”不可选且固定末尾。分组标题单击按既有待选择规则工作，双击普通分组标题可直接选中该组并进入小组多选；分组标题最右侧保留网站多选入口：首次点击后按钮变为“选择”并进入待选择状态，点击标题进入分组选择、点击卡片进入链接选择；进入小组多选后卡片链接不可打开，已进入一种模式后只能用“切换”按钮进入另一种待选择状态，空白、Esc 或清空最后一项会退出；选择圆圈固定在卡片右下角。
- 分组管理：顶部分组标签支持 450ms 长按定向管理，移动超过 8px 后由拖动意图接管并关闭管理器；“按分组显示”的标题三点按钮可直接管理对应分组。管理/新建弹窗使用透明遮罩与固定圆角外壳，桌面端完整展示 24 个图标，删除入口位于当前分组摘要行；普通分组直接在该入口 2 秒内点击两次删除，不再打开二级确认弹窗，非空组内链接统一进入回收站，受保护的“其他”保持只读。
- 添加、删除与回收站：主页右上角统一“添加”菜单可选择添加网站或新建分组；“全部－按分组显示”的每个分组标题左侧边界外提供仅含“+”的圆形插入入口。桌面仅在紧凑标题区、加号自身命中区、键盘焦点或菜单展开时揭示，经过整行空白和右侧网站多选按钮不会显示；链接拖放的整行空白命中范围保持不变。网站删除与回收站永久删除使用 2 秒内二次点击确认。设置－数据可恢复、全部恢复、逐项永久删除或清空链接回收站，并可选择 7/30/90 天或永不自动清理；默认保留 30 天。所有临时操作消息 5 秒后关闭。
- 设置侧栏：点击侧栏外区域时，干净草稿直接关闭；有未保存修改则先询问继续编辑或放弃并恢复已保存设置。壁纸“在页面拖动调整”期间停用外部关闭层，保证页面手势继续用于位置和缩放调整。
- 扩展 popup：双页签 + 书签导入。
- 工程记忆 Wiki 本身：75 篇日志 + 知识层 + 12 篇 ADR + `npm run lint:wiki` 校验。

- 回收站快捷入口：设置按钮左侧新增同风格回收站图标，点击直接打开“设置－数据－链接回收站”并展开内容；拖拽期间普通卡片的 hover/focus 反馈保持中性，真实落点只显示低对比度虚线框，不再呈现相邻卡片实线蓝色选中态。

## 当前验证基线

- 单元：`npm test`（vitest），15 个测试文件、124 例全部通过；口径见 [[Wiki/测试与验证基线|测试与验证基线]]。
- E2E：`npm run test:e2e`（Playwright），56 条 test × 2 project（chromium + Pixel 7 移动端），本轮完整基线为 82 passed / 30 skipped；覆盖右上角回收站快捷入口直达“数据－链接回收站”、拖拽期间普通卡片不再误显示 hover 蓝色高亮、手动落点改为低对比度虚线，以及既有分组双重删除、回收站、整行空白链接拖放、分组块排序和待选择进入/“切换”网站与分组多选，并验证双击分组标题直接进入小组多选、小组多选下卡片链接不可打开、窗口失焦会清理拖拽浮层。
- 扩展版本：`public/manifest.json`、`dist-extension/manifest.json` 与固定解压交付目录均为 1.1.40；网页包版本 `package.json` 仍独立使用 1.0.0。
- 多选视觉状态：待选择时右侧按钮由“多选”变为蓝色“选择”，同时编辑、删除和管理分组入口均锁定；进入任意多选状态后每个分组标题左侧都显示圆形选择框；链接多选时分组标题主区域与管理入口锁定为不可交互，卡片编辑/删除入口也禁用，仅保留“切换”；分组多选时管理入口禁用，标题仍可用于选中/取消，左侧圆形勾选标记未选为白色、已选为蓝色，选中分组使用加深后的浅蓝背景与蓝色虚线框包围标题、卡片网格和添加网站卡片，卡片链接不可打开；再次点击标题或链接只取消对应选择，取消最后一个链接后仍停留在链接待选择状态；从一种多选模式切换到另一种待选择状态后，再点一次同一“选择”按钮会立即退出，不会在待选择目标之间循环。
- 分组拖动反馈：被拖分组保持蓝色虚线来源框，虚线内侧由同一块蓝色底完整填充，标题与卡片内容使用 0.68 透明度保留可读性；多选和拖动状态不再绘制紧凑标题区域的实线内框，避免与外层虚线重复；顶部标签的图标与数量也提高到 0.52，不再出现过度模糊的整组背景；多选与拖动外框统一使用更紧凑的 15px 圆角。窗口失去焦点或页面进入隐藏状态时，网站/分组拖拽立即取消并清理 dnd-kit 传感器，浮层与来源状态不会残留。

## 当前限制与遗留问题（5 项）

1. **移动端 E2E 并发超时线索**：`playwright.config` 设 `fullyParallel: true`，移动端 E2E 有并发超时历史；本轮完整实跑未复现，仍需持续观察。
2. 原生新标签页搜索框不可嵌入（浏览器平台限制）。
3. 无痕窗口不接管新标签页（平台限制）。
4. 扩展无法自行固定到工具栏（平台限制）。
5. 拖拽在极端密集网格与复杂缩放下仍值得持续观察；1.1.6 已改为实时卡片交叠面积并保留 18px 滞回。
