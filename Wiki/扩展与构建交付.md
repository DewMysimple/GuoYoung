## manifest 与权限

- 扩展 manifest 为 MV3；常驻 permissions 为 `favicon` / `activeTab` / `bookmarks` / `search` / `storage`，浏览历史使用首次点击时申请的可选 `history` 权限，**不申请全站读取权限**。
- `history` 权限会让浏览器显示“读取和更改浏览历史”警告；权限被拒绝时只关闭历史能力，不影响收藏主页。
- 版本号以 `public/manifest.json` 为单一真源（当前 1.2.47）；网页构建与扩展构建都从该文件复制 manifest，交付前须核对产物版本。

## 验收产物归档

- `artifacts/site-hub-extension/` 与 `artifacts/site-hub-extension.zip` 是固定交付路径，不纳入版本子目录。
- 正式截图和录屏按 `artifacts/releases/v<manifest.version>/screenshots|recordings/` 归档；截图脚本与 E2E 从 `public/manifest.json` 读取当前版本并自动创建目录。
- 早期无版本截图保存在 `artifacts/legacy/screenshots/`；Playwright 原始录屏和本地服务器日志分别保存在 `artifacts/working/raw-recordings/` 与 `artifacts/working/logs/`。
- 历史日志不可改写，其中旧的根目录产物路径仅作为当时记录；当前定位规则以 `artifacts/README.md` 为准。

## 安装与重新加载

- 用户从 `chrome://extensions` 或 `edge://extensions` 加载 `dist-extension/` 或 ZIP 解压后直接包含 manifest 的目录；后续交付按已授权的自动覆盖解压流程更新固定目录，重新加载交给浏览器，不由Agent打开扩展管理页或点击重新加载。
- 无痕窗口不接管新标签页（平台限制，见 [[Wiki/当前状态|当前状态]]）；扩展无法自行固定到工具栏（平台限制）。

## 平台硬限制

- 扩展无法读取页面 DOM（非内容脚本注入场景）；图标获取依赖 `favicon` 权限与回退链（见 [[Wiki/图标解析体系|图标解析体系]]）。
- Release 构建与 ZIP 上传已由 GitHub Actions 自动完成；版本递增按运行代码改动执行，标签推送按具体发布任务授权执行；不要求固定确认口令。

## GitHub Release 自动发布

- 当前发布仓库为 [`DewMysimple/GuoYoung`](https://github.com/DewMysimple/GuoYoung.git)。
- `.github/workflows/publish-extension.yml` 监听 `v<版本号>` 标签，也支持从 GitHub Actions 手动运行。
- 工作流在 Windows runner 上执行 `npm ci`、`npm run package:extension`，并从 `public/manifest.json` 校验标签版本；成功后创建或更新对应 GitHub Release，上传 `artifacts/site-hub-extension.zip`。
- ZIP 是 Release 的下载资产；`artifacts/site-hub-extension/` 和本地解压目录仍只用于验收或“加载已解压的扩展”，不提交到源码历史。
- 标准发版：递增 manifest 版本 → 完成验证并创建 Git commit → 推送当前分支 → 按发布任务创建并推送同版本标签（例如 `v1.1.20`）→ 在 Release 页面下载 ZIP。本地安装更新按自动覆盖解压流程交付，重新加载交给浏览器。
