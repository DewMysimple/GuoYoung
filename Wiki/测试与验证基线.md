# 测试与验证基线

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 本页记录测试分层与口径。数字以 2026-09-26 完成的本期完整流水线实跑为准。

## 测试分层与入口

- **单元**：`npm test`（vitest），**45 个测试文件、341 例**，覆盖 `src/lib/` 与组件逻辑。
- **E2E**：`npm run test:e2e`（Playwright），十七个业务域测试文件，共用 `e2e/fixtures.ts`，**105 条 test**。
- **类型**：`npm run typecheck` 及 build 内的 `tsc -b` 启用 strict、noUnusedLocals、noUnusedParameters；未使用声明会阻止构建。

## E2E 计数口径

- Playwright `projects` 含 **chromium + mobile(Pixel 7)** 两个；105 条 test 在两 project 上各跑一次，理论 **210 次执行**。1.1.97 使用独立端口 4211、单 worker 完整实跑为 **166 passed / 44 skipped / 0 failed**；不把跳过计为通过。
- 完整验收与 CI 使用单 worker；桌面专用场景在移动 project 中明确跳过。保留 fullyParallel 能力用于按需并发，不将旧并发超时线索写成已证实的当前缺陷。
- 多工作树并存时用 `PLAYWRIGHT_PORT` 选择独立端口，Vite 使用 `--strictPort` 禁止自动换端口；复用服务前必须确认返回当前工作树代码。此前启动修复分支首次默认 4173 复用了另一个工作树的旧服务，新增首帧断言复现深色描边，该次运行已中止，不计入有效通过基线。
