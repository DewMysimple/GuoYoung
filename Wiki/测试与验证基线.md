# 测试与验证基线

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 本页记录测试分层与口径。数字以 2026-08-24 的完整流水线实跑为准。

## 测试分层与入口

- **单元**：`npm test`（vitest），**15 个测试文件、122 例**，覆盖 `src/lib/` 与组件逻辑。
- **E2E**：`npm run test:e2e`（Playwright），入口 `e2e/site-hub.spec.ts`，**53 条 test**。
- **类型**：`npm run build` 内含 `tsc -b` 类型检查，是每轮流水线第一关。

## E2E 计数口径

- Playwright `projects` 含 **chromium + mobile(Pixel 7)** 两个；53 条 test 在两 project 上各跑一次，理论 **106 次执行**；本轮结果为 **77 passed / 29 skipped**。
- 移动端因 `fullyParallel: true` 存在并发超时历史线索（见 [[Wiki/当前状态|当前状态]] 遗留项 1）；本轮完整实跑未复现。

## 演进曲线

- 单元用例随功能轮次从 12 例增长至 122 例；E2E 从 6 条增长至 50 条。
- 拖拽相关修复（冻结槽位、18px 滞回、实时交叠落点）与分组定向管理均配套回归用例，纳入 [[Wiki/拖拽交互契约|拖拽交互契约]] 验证。
- 非手动跨组迁移覆盖三条导航边界：“全部-按分组显示”迁移后保持“全部”；具体分组拖到目标标签持续 450ms 后在松手前预览目标分组并在释放后持久化迁移；桌面端还覆盖不松手拖回来源标签、预览切回来源分组并以同组无操作结束。前两条包含桌面鼠标与 Pixel 7 触屏覆盖。
- 1.1.13 新增分组顶部/分组区双入口排序、分组间插入、全部与具体分组批量迁移、非手动批量迁移、标签栏边缘自动滚动、网站两步删除和透明弹窗遮罩覆盖；桌面与 Pixel 7 都验证普通链接点击未被 50px 待激活手势误抑制。
- 1.1.15 将分组纵横边界覆盖升级为松手前实时让位：E2E 断言越界后相邻标签/分组立即移动、活动虚线槽进入预计位置且不叠加独立边界框，反向越界或 Esc 后恢复原坐标；键盘 live region 与标签边缘自动滚动覆盖继续保留。
- 1.1.16 新增“目标框回到来源槽后松手保持原序”回归，覆盖拖拽提交只认当前 `SiteDropIntent`；同时覆盖分组删除最终方案两次点击、方案切换/超时取消、长按管理转拖动关闭弹窗及左侧常驻插入按钮。
- 1.1.17 覆盖多选勾选位于卡片右下角、分组标题插入入口的桌面悬停/触屏常驻及前后插入、“其他”仅前插、标题区域 Space/Enter 无效，以及设置侧栏干净外部关闭、脏草稿继续编辑/放弃恢复、壁纸页面调整模式豁免；1.1.18 继续校验插入入口仅显示加号、视觉中心位于分组内容边界外，且分组图标保持与内容左缘对齐；1.1.19 模拟鼠标从标题经过外侧空隙移到按钮，断言圆形入口全程保持显示并具有非空阴影；1.1.20 改为先停留页面空白处，再直接进入隐藏按钮区域，确认入口不依赖分组标题 hover 即可揭示。
- 1.1.21 覆盖 v8→v9、回收站写入/恢复/过期/永不清理、非连续分组块顺序和“其他”固定；E2E 覆盖分组删除不再出现二级弹窗、回收站展示、空白标题行不揭示加号、加号自身可直达、标题就近网站多选及非连续分组块拖拽。
- 1.1.22 覆盖“多选”待选择状态不显示标记、标题点击进入分组多选、卡片点击进入链接多选、两种模式仅经“切换”互换、空白/Esc/清空最后一项退出，以及移除左侧分组选中控件；桌面与 Pixel 7 均验证。
- 1.1.23 增加待选择按钮深色状态、链接多选时分组标题主区域不可交互、分组多选时左侧插入入口替换为浅/深两态复合勾选框的组件与 E2E 断言。
- 1.1.24 增加待选择按钮蓝色确认态、无方框内容的圆形分组勾选，以及重复点击标题取消单组但保留分组多选目标的组件与 E2E 断言。
- 1.1.25 增加待选择按钮“选择”文案、小组多选时卡片链接不可打开的组件与 E2E 断言；1.1.26 增加任意多选状态下分组标题左侧圆形选择框，以及小组多选禁用分组管理入口的组件与 E2E 断言；1.1.27 增加选中分组外框覆盖整个分组内容区、标题不再绘制独立选中框的 E2E 视觉样式断言；1.1.28 增加选中分组浅蓝背景的计算样式断言；1.1.29 增加多选下卡片动作禁用、取消最后链接仍留在待选择状态及分组拖动透明度的组件与 E2E 断言；1.1.30 增加待多选状态下编辑、删除和管理分组入口禁用的组件与 E2E 断言；1.1.31 增加链接多选切换到分组待选择后再次点击“选择”即可退出的回归断言；1.1.32 增加小组多选加深背景、拖动源可读性和窗口失焦取消拖拽的 E2E 断言；1.1.33 增加小组多选与分组拖动整组外框 18px 圆角的 E2E 断言；1.1.34 增加小组多选与分组拖动蓝色底填满虚线外框内侧的计算样式与截图巡检，并新增桌面拖动源截图；完整流水线保持 122/122 单元、77 passed / 29 skipped E2E，失焦回归 3 passed / 1 skipped。

## 每轮五步流水线

- 1.1.35 追加小组多选外框的 computed `box-shadow` 回归断言，确保蓝色填充不再包含紧凑标题区域的 `inset` 实线内框。

1. 类型检查（`tsc -b`）。
2. 单元测试 `npm test`。
3. E2E `npm run test:e2e`。
4. 生产构建（`build` / `build:extension`）。
5. 真实浏览器截图巡检 + `npm run lint:wiki`。

## 视觉巡检不可替代

- 布局/拖拽手感/图标清晰度等**必须真实浏览器截图人工巡检**，自动化无法完全覆盖；尤其拖拽抖动类问题需录屏逐帧核对（见 [[Wiki/日志/工程讨论/第002次|工程讨论·第002次]]）。

## 已知不稳定用例

- 移动端 E2E 并发超时（遗留项 1）；外部 GitHub 导航已改为本地路由响应，避免验收结果受网络速度影响。
- 拖拽落点类用例对渲染时序敏感；1.1.6 已增加偏心抓取、松手前目标框移动、双向、跨行与跨组回归。
