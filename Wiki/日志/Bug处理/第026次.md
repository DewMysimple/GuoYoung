## 已确认的决策

- 居中式弹窗外壳四角必须完整、对称且不承担滚动；标题和底部操作固定，只有内容区或列表承担滚动。单侧圆角、直角、滚动条贴边截断和子元素越界覆盖列为 UI 回归硬禁例。
- 收藏主页、GitHub 页面和具体分组的非空搜索统一查找两个工作区的全部活动收藏，结果平铺并显示工作区/分组来源；清空搜索恢复开始搜索前的上下文。
- 浏览器历史页面继续保持独立搜索边界，不参与收藏全局搜索；回收站链接不参与收藏搜索；GitHub 官方根入口在 GitHub 页面继续只通过固定入口呈现。

## 检查与操作

- 回读 `AGENTS.md`、项目知识 MOC、当前状态、外观、数据、扩展交付和测试基线，确认本轮不更换 `site-hub:v1`、不升 state 版本、不修改历史记录边界。
- 根因确认：作者仓库导入弹窗同时拥有 `max-height`、外层滚动样式和内部列表滚动；通用 `.dialog-content` 的后置规则覆盖了外层 `overflow: hidden`，长列表时原生滚动条贴住右边界并破坏圆角。
- 将作者导入外壳改为固定高度的纵向 flex 容器，外层隐藏溢出，预览区收缩并把滚动空间交给 `.github-import-list`；补充桌面和移动端外壳/内部列表几何断言。
- 将收藏搜索从仅主页“全部”或局部分组范围扩展为任意收藏页面的活动收藏全库；记录搜索起点，在清空关键词时恢复工作区和分组，显式导航仍可重置搜索。
- 使用 `redesign-existing-projects` 与 `make-interfaces-feel-better` 的现有项目审查原则复核弹窗层级、内外圆角、滚动边界和移动端留白，未引入新装饰或贴边滚动条。
