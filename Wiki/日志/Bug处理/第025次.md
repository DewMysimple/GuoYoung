## 已确认的决策

- 浏览器权限与历史方法统一兼容 Promise 和 callback 两种 Chromium API 调用形式；授权后主动重查权限并刷新历史视图。
- 授权异常不再静默停留在授权页，显示可重试的错误提示；拒绝授权仍只影响历史视图，不影响收藏主页。
- 顶栏入口顺序为品牌、收藏主页、历史记录；两者在同一新标签页内切换，历史内容区的返回按钮继续保留。
- 历史列表左侧保留勾选框和网站图标，扩大左侧内边距与列间距，并让日期标题、批量工具栏和历史行使用统一基线；移动端采用独立紧凑参数避免横向溢出。

## 检查与操作

- 回读项目契约、知识 MOC、当前状态、扩展交付、测试基线和日志模板；确认不更换 `site-hub:v1`，不新增收藏 state 字段。
- 根因确认：原适配层只按 Promise 读取 `permissions.request/contains` 与 `history` 方法；Edge callback 形式返回 `undefined` 时被误判为未授权或无结果，且授权异常被静默吞掉。
- 在浏览器运行时类型中加入 callback/Promise 结果联合类型，并在历史适配器中增加统一 callback 桥接与 `runtime.lastError` 检查。
- 调整历史行的网格列、内边距、图标尺寸、日期/工具栏左对齐和移动端覆盖规则；沿用现有设计令牌，不新增视觉竖栏。
- 使用 redesign-existing-projects skill 检查现有层级、留白、响应式和焦点状态，采用局部 CSS 调整而非重写历史视图。
