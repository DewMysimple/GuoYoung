## 已确认的决策

- 用户现场反馈 1.2.32 仍性能差，确认恢复 1.2.15 的卡片宿主原生 backdrop-filter 核心机制；不采用 SVG 壁纸采样、卡片固定 CSS 壁纸副本或永久每卡合成层提示。
- 用户明确要求改完暂停、由用户审核，本轮不打开浏览器，不执行 E2E、截图、录屏、逐帧分析或性能采样。该具体指令优先于 AGENTS 固定流水线的浏览器步骤；没有执行的验证不得记为通过。
- 用户后续要求暂不交付 ZIP，改以同一原配置与壁纸的本地开发服务器审核；不覆盖原固定扩展目录，不清理历史验收资料。manifest 源码/构建版本为 1.2.33，本轮仍按协作契约提交并推送 origin，发布标签不新增。
- 远端闪线仍是必须处理的目标；稳定原生材质与前景交互是本轮代码整改方向，但源码和非浏览器检查不能证明真实远端像素已无异常。性能和闪线均保留“待用户审核”，不提前关单。

## 检查与操作

- 回读 AGENTS、知识 MOC、当前状态及外观、拖拽、测试、扩展交付主题页，核对当前源码与历史 1.2.15 / 1.2.24–1.2.32 机制。
- 根因：1.2.29 首次把原生背景模糊替换成逐卡 SVG 壁纸图源，滚动坐标变化使滤镜失效；1.2.32 删除 JS 滚动更新后仍给每卡绘制固定壁纸背景和 CSS blur，浏览器依旧逐卡 Paint / Raster。共享图源不等于共享滤镜位图，无长任务与 rAF 单项数据不足以证明原生版本的性能已经恢复。
- 只读 ABBA 对照来自本轮修改前保留报告：同一 Chromium 151.0.7922.34 / GPU、117 张同尺寸卡片、相同壁纸和 24px 磨砂，无 CSS 注入；1.2.15（6cc39b1）与 1.2.32（8644580）各两轮。80 次小幅滚动的 Paint 分别为 0 / 9,602–9,616，RasterTask 为 79 / 8,119，合成层为 169 / 626–628；1.2.32 的 117 卡及添加卡片均重复 Paint。该对照不能外推为 1.2.33 的运行结果或所有机器固定开销。
- 用卡片宿主原生背景滤镜替换当前绘制链，可见壁纸恢复 img；清除源图几何/滤镜发布、设置源刷新事件、transform 回退协议及旧三处永久前景/标题/favicon 合成提示。静止与悬停保持同一背景材质、阴影和几何，边框颜色提供局部反馈。仅保留从原生背景 SourceGraphic 处理的可选折射位移贴图，不读取 SVG 壁纸或新增滚动坐标同步。
- 同配置开发审核使用独立 loopback origin 与忽略的本地素材，入口为 http://127.0.0.1:5183/__mysimple_review__/setup；不打开浏览器。审核使用用户原始导出，主工作区保留原分组显示、GitHub 保留原平铺，未改用平铺性能夹具。仅将本地壁纸资源引用改为同一原 PNG 字节的本地 URL，布局与原玻璃/顶栏/侧栏参数保留；每次审核会话用标记避免重复初始化。私人配置/壁纸不进入源码、Wiki 或公开截图，服务器连通不代表画面或性能已经验证。
