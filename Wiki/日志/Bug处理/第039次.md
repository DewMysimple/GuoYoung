## 已确认的决策

- 正常前景按钮的淡入和位移动画必须保留，不能通过去动画掩盖远端重绘异常。
- 产品运行代码维持用户指定回退提交的 1.2.25。本轮只提交诊断工具、动画回归断言与文档，不递增扩展版本、不交付新的修复 ZIP。
- 每个实验的有效桌面录制逐帧生成基准差分与相邻差分热力图，任意非零变化增强显示，不裁去空白区域、不用容差掩盖条带。
- 全局 opacity 合成提示虽消除局部卡片条带，却在其他区域留下变化，已经撤回。显式壁纸来源实验尚不能作为完整产品修复。

## 检查与操作

- 使用外部导出配置与原壁纸在隔离 Edge 中复现，不写回用户配置；配置和私人素材不提交。
- 浏览器截图/CDP 录屏未可靠捕获原始条带；改用桌面 GDI，并以 Desktop Duplication 交叉核对，两者均捕获类似远端竖条。
- 增加前台窗口守护、真实系统鼠标移动和 DOM 指针事件记录。一次被其他窗口遮挡的旧采集已判无效并排除；本地清理被自动审批阻止，未绕过限制。
- 比较背景滤镜、父层、材质层、预建合成层与显式壁纸来源等实验。局部裁剪归零并不代表整屏通过。
- 本地总查看器收录 37 组、17,436 帧，支持双热力图逐帧浏览；最新分析脚本为每次采集单独生成 HTML 查看器及 JSON 统计。热力图不遮任何像素，远端统计另行排除实际交互区和异步图标。

## 问题、结果与下一步

- 根因定位到**背景采样与局部交互重绘之间的绘制依赖**：远端变化并非对应控件收到悬停事件；替换活背景采样后大面积条带消失，单纯稳定合成层不足。尚无浏览器内部追踪能确定具体引擎缺陷，因此不把 GPU 驱动或某个 Chromium 内部实现写成已证实根因。
- 1.2.25 现场问题重新打开，旧关闭日志保持原样。诊断已取得可重复证据，修复目标仍未完成。
- 后续将显式来源实验与保留原背景采样的更小方案作比较；生产方案必须验证滚动、壁纸构图/缩放/遮罩、磨砂、折射、菜单、拖拽及扩展模式，再递增版本并交付。不能把固定构图下的实验零差异当作全部验收通过。
