## 检查与操作

- 按版本核对绘制路径：1.2.22 / 1.2.23 在卡片宿主使用原生 backdrop-filter；1.2.24 移入独立 ::before；1.2.25 增加父卡 will-change 提示；1.2.29 改为按卡片位置使用 SVG feImage 显式壁纸并由 JS 跟随滚动；1.2.30 / 1.2.31 分批读写、复用资源和收窄监听。
- **根因**：1.2.29 以后把卡片屏幕坐标变化转成滤镜采样输入变化。后续治理降低了 JS 调度、样式重算与资源维护开销，仍保留逐卡采样位置失效和浏览器重新栅格化路径；滚动位置稳定不等于模糊像素已同步。共享 SVG 定义也不能据此推断每卡只绘制一次或栅格任务消失。
- 同机对照的小幅滚动 RasterTask 计数为 1.2.31 的 6,540、1.2.22 的 110。1.2.31 小幅场景没有长任务，但 rAF p95 为 50ms、超过 33ms 的间隔有 36 次；1.2.22 对应 p95 为 10.9ms、超过 33ms 为 0。任务计数和回调间隔仅用于该机器、该输入场景的比较，不等同 GPU 总耗时或普遍帧率。
- 真实桌面 60fps 返回比较不平滑、容差为 0，首排 11 卡对初始参考：1.2.31 两次返回分别在位置稳定后迟到 2 / 1 帧（约 33.3 / 16.7ms），1.2.22 两次均为 0 帧。旧版另有悬停触发的远端持续卡片条带，故直接回退旧路径不能同时解决两类问题。
- 原始证据保存在 artifacts/working/frost-rebuild。性能摘要为 live-result/report.json 与 1.2.22-result/report.json；严格返回摘要为 current-desktop/raw-return.json、v22-desktop/raw-return.json；旧版悬停摘要为 v22-hover/heatmap-report.json。报告与原始录制留在本地产物目录，文档只记录结论与范围。
- 旧稳定时间脚本以各静止片段末帧为锚点，并有平滑/阈值，可能漏掉第二次返回的单帧细微变化；稳定错误也可能得到 0ms。第041次确有候选生产首排 11 卡、两次返回共 22 次额外零差比较，不能描述为历史从未比较初始参考；该候选结果也不能泛化为最终 1.2.31 已通过桌面复录。
- 新方案光学偏差的原因是原 img 的像素落点/变换绘制与 CSS 背景局部绘制路径不同，正确的连续几何与 blur 半径并不能保证离散像素一致。统一可见壁纸与卡片的 CSS background 绘制方式，保留隐藏 img 测量原生几何和过渡；没有加入固定相位偏移、滚动跟踪或放宽阈值。
- 绘制边界继续按实测保留：前景工具、分组标题/显示控件合成提示能抑制重新栅格化；分类数量标签不再重复嵌套模糊。真实拖拽中的 favicon 圆角出现 17 像素、最大 1 色阶差异，增加 favicon-frame 子层合成提示后严格回归通过。不能据旧逐卡链被替换就宣称全部历史合成提示无效。
