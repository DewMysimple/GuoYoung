## 已确认的决策

- 根因是排列方式只保存在 `App` 的临时 React 状态，未写入 `site-hub:v1`；修复为按 `main` / `github` 工作区持久化排列方式，并保留旧 `sortMode` 作为兼容回退。
- state 从 v13 迁移至 v14；迁移只补缺失或非法排列值为“手动排列”，合法已有值不覆盖。
- 选择“热量排列”时，卡片底部信息行保留分组信息并新增可见的“热量 N 次”及火焰图标。

## 检查与操作

- 回读 `App`、`use-site-hub`、`storage`、`SiteCard` 与热量排序测试，确认排序计算本身已按 `clickCount` 降序，缺陷只在选择状态生命周期与反馈信息。
- 将排序模式抽为共享类型，接入存储校验、v13→v14 迁移、工作区选择与重置保留逻辑。
- 扩展版本递增至 1.1.67，生成扩展构建、固定解压目录和 ZIP；使用真实 Chrome 桌面、Pixel 7 与深色视口截图检查热量排序按钮和卡片次数。
