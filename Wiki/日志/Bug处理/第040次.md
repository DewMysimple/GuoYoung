## 已确认的决策

- 保留原前景淡入/位移过渡、拖拽 transform 所有权和保存配置。静态玻璃改用显式壁纸图像，解除对其他 UI 绘制结果的背景采样依赖。
- Chromium 共享同参数壁纸 SVG 来源，按各表面实际屏幕位置裁切、磨砂、折射和合成；无壁纸、减少透明度、其他引擎保留原降级路径。直接变换的普通控件和 body Portal 保留原背景材质。
- 拒绝全局滤镜造成构图改变、同节点合成提示造成玻璃失效等假通过方案。不能删除正常动画或放宽远端像素断言。
- 交付 1.2.29；不重复使用排查期间已撤回的候选版本号。私有配置、壁纸、视频及热力图不提交。

## 检查与操作

- 在第039次已证实的桌面原始条带上继续对照，身份滤镜和层提示仍残留远端变化；显式来源解除大面积关联重绘。
- 最小实验确认内部 SVG 片段图像被引用为普通滤镜输入时，同一滤镜元素的 `will-change: transform` 可使本机 Chromium 不绘制该滤镜。将滤镜留在卡片伪元素，稳定父层与前景，并新增真实光学验证。
- 每段有效桌面录制逐帧输出整屏基准/相邻双热力图。总查看器收录 48 组、26,338 帧，失败及输入偏移实验明确标注，不隐藏空白区或非零色差。
- 发现原生扩展浏览器 HWND 原点少计 87px 顶栏，第一段817帧录制未实际经过卡片，判为无效通过证据。新增原生输入与 DOM 坐标校准、第二点精确复核后重新录制；网页既有记录的坐标一致。
- 固定扩展目录覆盖复制当前26个文件，保留一个旧 CSS 供未重新加载的页面使用；不删除历史验收目录。

## 问题、结果与下一步

- **根因**：玻璃的活背景采样使静态远端材质与左侧局部交互重绘存在绘制依赖。远端控件没有收到悬停事件；替换输入后原条带消失，正常交互继续。证据不足以指认某个 GPU 驱动或 Chromium 内部缺陷，故不作此类断言。
- 工程复现场景修复及扩展交付完成，用户安装后的现场确认尚未取得。更新后到扩展管理页点“重新加载”，打开新标签复测。
- 验收必须同时检查玻璃确实绘制、鼠标确实命中和整屏逐帧差分。仅静态截图、同节点层提示、裁剪归零或不命中的零差分均不足以关闭此类问题。
