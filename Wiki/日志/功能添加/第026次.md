## 已确认的决策

- `https://github.com/` 保持为主收藏中的单条 `SiteItem`，主页显示普通卡片，GitHub 页面在搜索框下显示同一条数据的官方共享入口，不创建重复收藏。
- GitHub 官方入口固定显示在 GitHub 页顶部布局中，不随平铺/分组模式消失；编辑、删除和旧版链接放回主页通过入口的更多菜单完成。
- 原“GitHub 收藏已整理”大块提示移除，迁移撤销保留在 GitHub 页更多菜单，并遵守已移动、删除或修改链接不覆盖的保护规则；官方根入口不参与自动迁移。
- `displayModeByWorkspace` 让主页与 GitHub 工作区独立保存显示方式；state 从 v11 迁移到 v12，旧 `displayMode` 只用于补全主页，GitHub 默认平铺。
- 扩展 popup 依据活动标签页 URL 选择工作区：GitHub 具体页面只显示 GitHub 分组并记忆上次分组，GitHub 根页按共享主页入口处理，偏好不进入收藏导出。
