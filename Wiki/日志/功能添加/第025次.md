## 已确认的决策

- 顶栏顺序固定为 `Mysimple → 收藏主页 → GitHub → 历史记录`；GitHub 页面与主收藏共用本地收藏库和整库导出。
- GitHub 只识别 `github.com` 及其子域名，不接入 GitHub API，不要求登录，也不跨浏览器或设备同步。
- 旧 GitHub 链接首次进入页面时移动而不复制，并提供一次性恢复原分组；恢复只作用于仍未被用户移动、删除或修改的迁移项。
- GitHub 工作区预置“仓库、工具、文档、其他”四组，“其他”受保护；GitHub 页面新增、编辑、拖入与导入拒绝非 GitHub URL。
