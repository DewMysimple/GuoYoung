## 已确认的决策

- GitHub 官方入口保留现有“打开 GitHub”CTA 和三点管理菜单；除管理菜单及其操作控件外，入口卡片区域均可打开 GitHub，并沿用新标签页语义。
- 浏览器历史记录的标题/URL 链接改为新标签页打开，当前历史视图不被替换；沿用收藏链接的 `noopener noreferrer` 安全属性。
- 不修改 `site-hub:v1` 数据结构和历史数据边界；扩展行为变更递增 manifest 版本并生成 ZIP。

## 检查与操作

- 读取 `AGENTS.md`、项目知识 MOC、当前状态、测试基线、扩展交付说明及交互细节技能，确认本轮为功能添加，不涉及拖拽契约和 state 迁移。
- 复用普通收藏卡片的透明整卡链接层，为 GitHub 官方固定入口增加独立的整卡命中层，并保留 CTA、三点菜单、编辑、删除和迁移操作的独立命中。
- 为浏览器历史条目补充 `_blank` 与 `noopener noreferrer`；新增组件断言和桌面/Pixel 7 E2E，验证新标签页不会替换当前视图。
- 递增 `public/manifest.json` 至 1.1.59，生成扩展构建目录与 `artifacts/site-hub-extension.zip`，并巡检 1.1.59 桌面/移动端截图。
