## 已确认的决策

- 主页只有“全部”视图且搜索词非空时跨查 `main` 与 `github`；具体分组和 GitHub 页面继续隔离，跨工作区结果统一平铺并显示来源。
- 作者导入只读取公开仓库，不接入登录或 Token；必须先完成全部分页请求并预览，确认后才写入收藏。
- 作者分组按来源复用或按登录名加后缀创建，活动收藏和回收站 URL 全局去重；刷新只追加，不删除旧收藏或重新加入回收站 URL。

## 检查与操作

- 增加 GitHub 作者主页解析、用户/组织判断、串行分页查询和 403/429/分页失败错误处理。
- 增加 v12→v13 迁移、`githubImportSource` 来源记录、整库导出保留来源和分组资源包排除来源。
- 增加导入弹窗的默认全选、单项取消、已收藏/回收站标记、确认写入与刷新入口；扩展声明 `https://api.github.com/*` 主机权限。
