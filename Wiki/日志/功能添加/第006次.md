## 已确认的决策

- 拖拽判定改为"按压时长 + 容忍位移"双条件，桌面 150ms / 7px，触屏 240ms / 12px。讨论轮拍板的原则是：拖拽不能只靠"移动了几像素"判定，必须同时满足时间与位移意图。被否决的是继续用单一 3px 位移阈值，理由是快速点击时手腕的自然位移就会触发拖动。
- 设置采用"预设 + 高级微调"两层结构，常用项前置、高级颗粒度收进二级区域。被否决的方案是把所有滑杆一次性铺开，理由是会让设置从"调整"变成"劝退"。
- 本地壁纸压缩后存入 IndexedDB，收藏状态只保存引用。被否决的方案是把图片直接写进当前 JSON 状态，理由是会迅速超过扩展存储额度。
- 搜索历史只记录用户实际发起的网页搜索（回车或点击历史项），不记录普通收藏筛选文字；导出时排除搜索历史与本地壁纸文件，网络壁纸地址可导出。这是明确的隐私边界决策。
- 移除"这个分组还是空的"和"没有找到匹配的网站"两条提示横幅，空分组或零结果时只保留标题、数量与添加卡片。
- 分组管理重做为桌面双栏弹窗（左侧可拖拽列表、右侧编辑区），图标库扩充到约 24 个统一图标；导入导出从分组弹窗迁至设置的数据区域。被否决的是继续在单行里堆拖拽、图标、名称、数量、下拉与删除六种元素。
- 设置采用草稿模式：调节时实时预览，点保存才持久化，取消恢复到打开设置前的外观；"恢复默认外观"不影响收藏、分组与搜索历史。

## 检查与操作

- 确认误触根因：桌面拖拽当前只要求移动 3px，因此快速点击伴随的自然位移即可越线。
- 确认分组管理问题的具体形态：每一行同时承载六类控件，信息密度过高。
- 核对 dnd-kit 当前版本是否原生支持"延时 + 容忍位移"的组合约束，确认支持，因此无需重写传感器，也能保留键盘排序。
- 数据层先行升级到 v5，把外观、壁纸、搜索历史做成可迁移、可校验的统一状态。

```
storage key 保持 site-hub:v1
state → v5
appearance：主题色 / 布局预设 / 六项布局数值
wallpaper：来源 / 填充 / 焦点 / 模糊 / 遮罩 / 本地资源引用
searchHistory：查询文字 + 搜索时间
```

- 旧版本读取时自动补充默认外观与空搜索历史，不覆盖现有站点、分组、顺序或主题偏好。
- 动态布局通过 CSS 自定义属性下发，所有输入读取时校验并夹取到安全范围，避免旧缓存或非法数值破坏页面。
- 把顶部主题按钮替换为齿轮入口，桌面打开约 440px 右侧面板，手机端使用全屏面板。
- 设置分为外观、壁纸、数据三区；外观含系统/浅色/深色、6 个强调色预设与自定义颜色；布局提供紧凑、标准、宽松三档预设，选择后仍可进入高级区微调。
- 落地高级六项参数与默认值。

```
字号 85–120% / 卡片宽 132–260px / 卡片高 112–240px
间距 4–32px / 内容宽 960–1920px / 圆角 4–28px
默认：100% / 160px / 140px / 12px / 1600px / 16px
```

- 壁纸支持本地图片与网络地址：本地图片限制 20MB，自动缩放到最长边 2560px 并压缩为 WebP 后入库；提供铺满/完整显示、九宫格焦点、0–20px 模糊与 0–80% 明暗遮罩；图片失效自动回退主题背景并在设置中提示，不阻塞页面使用。
- 搜索历史实现去重、最近优先、上限 10 条；聚焦搜索框时展开，可键盘选择、单条删除或全部清空，点击历史项立即重新搜索。
- 把分组管理重构为双栏结构，手机端自动改为上下布局；"其他"继续固定末尾且禁止删除、改名与移动。
- 图标选择改为可视化网格，扩充至约 24 个统一图标，含数据库、终端、云、聊天、购物、游戏、音乐、图片、日历、图表、机器人、收藏等。
- 把"恢复默认收藏"移入设置的数据区域，并保证其保留当前外观、壁纸与搜索历史。
- 跑类型检查，修掉迁移逻辑与组件接口上的边角问题。
- 真机验收重点放在两处"测试通过但手感可能不对"的地方：快速点击伴随轻微位移是否仍打开网站；长按后卡片是否实时让位、浮层宽度是否与原卡片一致。
