## 已确认的决策

- 历史记录按主域名聚合为站点大卡片，GitHub、ChatGPT 等使用品牌名，未知站点使用主域名；子域名归并到同一站点。
- 大卡片默认收起，可同时展开多个；展开内容继续按浏览器 API 能提供的 URL 粒度展示，不模拟无法稳定获取的单次 visit 记录。
- 选择、删除、权限、时间范围、搜索和实时刷新能力保持原有粒度与契约；站点卡片的展开状态只保存在当前页面会话，不新增收藏 state 字段。
- 采用收藏主页相同的响应式卡片网格，并使用 `auto-fit` 填满可用宽度，避免少量站点时卡片被挤成窄条。

## 检查与操作

- 阅读项目协作契约、当前状态、数据与存储契约、扩展交付说明和测试基线，核对历史权限、删除粒度与扩展交付要求。
- 新增历史站点分组纯函数与类型，重构历史页面为站点摘要卡片和 URL 子卡片；保留 URL 级选择、批量删除、权限重试和历史事件刷新。
