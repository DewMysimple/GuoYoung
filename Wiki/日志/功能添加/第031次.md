## 已确认的决策

- GitHub 官方入口整卡继续打开 `https://github.com/` 并计入一次点击热量；右侧主动作改为无文字的“刷新仓库”图标按钮，尺寸与三点菜单统一为 40×40。
- “刷新仓库”沿用现有作者仓库导入/刷新流程：在作者分组内刷新该作者，否则打开作者仓库导入流程；保留底部工作区级导入/刷新工具栏。
- GitHub 官方入口菜单只保留编辑和删除，移除“放回收藏主页”及一次性迁移撤销入口；旧 `githubMigration` 状态继续兼容读取。
