## 已确认的决策

- 网站备注为可选纯文本 `SiteItem.note`，新增和编辑共用原网站表单。卡片在访问次数之后、分类之前显示备注；不依赖热度排序，长内容单行省略并可通过提示查看。外观设置增加“显示网站备注”，默认开启；关闭只影响显示，不删除备注。
- state 升至 v28，迁移只补缺失偏好并保留有效收藏、备注及其他设置。`site-hub:v1`、扩展权限和锁定依赖保持；扩展版本升至 1.2.50。
- 正方形卡片按当前实际网格是否含备注预留一行，并遵守显示开关；根页面、导航和推开设置面板的安全宽度使用含备注的预算。无备注网格不因其他网格有备注而统一增大卡片；自由比例卡片继续依内容自然增高。
- 普通分组跳转均平滑滚动，长距离不设置总时长上限。滚动速度上限为每秒 1.8 个视口，两端分别渐入渐出，单次繁忙帧最多推进 50ms 动画时间；系统减少动态效果偏好保持原例外。用户确认高亮保留最后点击目标，直到手动中断后再跟随实际阅读位置。
- 扩展 popup 可直接输入新分组名称，并在一次保存中完成建组和添加当前网站；按活动 URL 选择主收藏或 GitHub 工作区，重复网站继续二次确认，同工作区同名组提示选择现有分组。取消仅撤销草稿，失败可重试，确认前不落空组；更新已有网站保留备注。
- 四处绿色说明文字复用公共 `HelpTip`，布局控件收进折叠区，三项布局预设继续保留。说明与折叠属于展示调整，原预览、保存、取消和键盘语义保持。

## 检查与操作

- 按 AGENTS 回读项目入口及数据、分组、设置和扩展契约，再以源码核对备注存取、卡片布局、导航生命周期、popup 写前重读和公共设置组件。
- 用户录屏为 5.375 秒、129 帧、24fps、240×750，逐帧发现“其他”蓝色高亮短暂闪现。源码根因为导航按钮 `pointerdown` 先清掉旧目标，后续 `click` 才设新目标，中间一帧按实际阅读位置选中末尾短分组；导航按钮按下不再提前释放目标，由点击同一事务接管，外部输入仍中断。
- 原生平滑滚动的近固定时长会压缩大跨度行程，新增公共滚动控制器按距离与视口速度推进；改目标从当时实际位置开始，取消帧与代际标记防旧任务回写，滚轮、滚动键、外部指针、失焦和页面隐藏停止任务。分组绝对坐标仍缓存，仅在点击或真实布局变化时读取，动画帧不遍历量取分组矩形。
- 备注链覆盖添加/编辑、更新时省略字段保留、显式空值清除、回收站/恢复、整库备份和分组导入导出、搜索。非法可选备注归一化为空，不因此丢弃整库；有效长文本不在存储迁移中截断。
- popup 新分组复用现有建组与网站状态函数，确认时重读最新数据，将两项变更合成一个快照后保存；同名与并发重复 URL 均在最新快照中检查。普通添加、浏览器书签页和 GitHub 分组偏好继续沿用原入口。
- 完整回归结束后独立只读复核 popup 和备注数据链：建组前检查最新同工作区名称及重复 URL，唯一保存点同时包含分组和网站；更新取最新备注而非初次加载快照。存储迁移、CRUD、整库及分组导入导出、删除恢复均保留可选备注，未发现本轮需求遗漏；生产截图与固定安装包仍另行核验。
