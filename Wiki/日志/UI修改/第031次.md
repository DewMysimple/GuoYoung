## 已确认的决策

- 历史时间范围默认使用“近 7 天”，控件改为圆润胶囊形并保留原生键盘与无障碍选择语义。
- 历史详情进入浏览器导航状态；页面内返回和浏览器原生后退都按“详情 → 历史总览 → 收藏主页”的层级退出，并由历史页接管滚动恢复。
- 设置、分组管理、新建分组、添加/编辑网站和 GitHub 导入面板统一提供标题栏“返回”入口，同时保留独立关闭按钮。

## 检查与操作

- 回读历史视图、App 顶层切换、弹窗标题栏与现有 UI 规范，确认历史筛选器原先使用较硬的 13px 圆角、默认范围为全部历史，顶层状态也未写入浏览器导航栈。
- 为历史总览和详情增加轻量 `history.pushState` 层级；关闭历史视图时清理当前层，详情列表期间设置 `scrollRestoration=manual`，避免浏览器原生滚动恢复覆盖页面定位。
- 为时间范围和面板返回入口补充组件与 E2E 回归断言；扩展 manifest 从 1.1.63 递增到 1.1.64。
