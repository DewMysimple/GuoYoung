## 已确认的决策

- 历史站点卡片必须遵循收藏主页 `SiteCard`：默认不渲染选择控件，进入“多选”后才渲染右下角圆形选择按钮；不使用历史页自定义的左上角原生复选框。
- 站点卡片点击改为进入历史详情子页面；详情页显示该站点下的 URL 卡片，历史列表卡片不再内嵌 URL，也不显示展开箭头。
- 历史搜索复用收藏主页的 `workspace-intro`、`search-panel`、`search-input` 结构，保证位置与设计令牌一致。
- 历史页只保留单 URL 删除和选择后的 URL 批量删除，移除清空全部、清理范围和清理搜索结果入口。

## 检查与操作

- 回读 `src/components/site-card.tsx` 中 `.site-card-topline`、`.site-selection-toggle` 和整卡链接行为，以及 `src/App.tsx`/`src/styles.css` 中收藏主页搜索结构。
- 定位历史卡片左侧空白根因：`.history-site-topline` 和 URL 顶部布局在选择控件隐藏时仍保留 `padding-left: 28px`；同时确认历史页仍保留卡片内 `CaretRight/CaretDown` 展开结构。
- 将历史站点卡片改为收藏主页同款右下角圆形选择控件；将站点摘要点击改为当前历史视图内的独立详情子页面；搜索表单改用收藏主页搜索类名。
- 删除历史清空确认对话框及其全部/范围清理调用；保留浏览器原生 URL 删除和 URL 级批量删除。
- 增加详情页、选择控件几何位置、无箭头/无清空入口和桌面/移动端截图检查。
