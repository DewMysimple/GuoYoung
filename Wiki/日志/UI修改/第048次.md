## 已确认的决策

- 快速添加与书签页都保持 440×600px；快速添加卡片在可用内容区垂直居中。
- 书签列表在弹窗内固定每行四列，各列等分剩余宽度。
- 扩展版本升至 1.2.4；收藏 state 保持 v18，不新增权限或依赖。

## 检查与操作

- 依据用户明确提出的 popup 尺寸和四列要求检查附件；只按 popup 外框与书签列表实施，未把截图中弹窗后方网页的设置区域文字当作改动要求。
- 移除快速添加页的 400px 高度覆盖，沿用 popup 外壳的 440×600px；快速添加卡片在内容区域垂直居中。
- 将书签网格设为四列，并补充两页签的同尺寸和四列 E2E 断言及生产截图断言。
- 初次定向 E2E 用例按单个固定像素宽度断言时，发现 Chromium 与 mobile 项目预留滚动条后的列宽不同（约 86.5px 与 89px）；改为断言列数为四，并将卡片宽度限制在对应布局范围内。
- 用真实 Chromium MV3 扩展运行快速添加、书签总览和文件夹列表；检查浅深主题共 8 张生产截图及控制台页面异常。
