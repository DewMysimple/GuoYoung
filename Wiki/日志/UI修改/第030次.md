## 已确认的决策

- 历史面板移除可见的大标题区，搜索框与收藏主页和 GitHub 保持同一顶部位置；数量统计、时间范围和多选收进下方工具栏。
- 历史站点与 URL 详情卡片共享主页卡片几何、标题、域名和底部信息布局。最近访问使用短日期，完整时间与访问次数通过整卡提示查看。
- 选择模式支持整卡选择、右下角圆形选择标记与 Esc 退出；详情链接在选择模式中不打开页面，单项删除暂时禁用。
- 进入站点详情回到页面顶部，返回列表恢复原滚动位置；读取失败提供重新读取。

## 检查与操作

- 根因：历史卡片外层同时应用 `.site-card` 与 `.history-site-card`，后声明的 `.site-card` 恢复外层内边距；内部摘要又叠加最小高度，内部按钮再次增加内边距，加上两行统计共同撑高卡片。
- 移除历史专属的重复卡片几何；保留外层 `site-card` 与共享内容类，摘要包装不再产生独立布局盒。
- 删除顶部大标题和历史页额外顶部内边距；修正移动端工具按钮继承全宽规则造成的额外换行。
- 浏览器回归发现选择链接被主页禁用规则覆盖，已使用历史作用域修复；大量记录截图发现详情保留列表滚动位置，补齐往返位置处理。
- 在生产网页构建上通过 Chrome 加载模拟历史 API，巡检 18 个站点、5151 条记录与 632 条 URL 详情；模拟数据不来自用户真实历史。
