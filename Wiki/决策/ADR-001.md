# ADR-001 采用 React 19 + Vite 7 + Tailwind v4 的无状态库单页工作台

[[Wiki/决策/MOC_决策|← 返回决策 MOC]]

## 背景

首版需要快速落地一个可高度自定义的本地网站收藏页。初期曾考虑套用现成模板导航页，但模板无法满足后续自定义分组、拖拽排序与图标体系等扩展需求。

## 决策

采用 React 19 + TypeScript + Vite 7 + Tailwind v4（Vite 插件形式，无独立 config）构建单页应用；状态集中在自研 hook（如 `use-site-hub.ts`），**不引入 Redux / Zustand 等状态库**。

## 影响

- 全局可调用的状态只有一个自研 store，降低心智负担与依赖体积。
- 所有跨组件状态读写必须经该 hook，新增状态字段须配套迁移逻辑。
- 与 ADR-003（存储键与迁移）协同，状态版本写入 state 内部。
