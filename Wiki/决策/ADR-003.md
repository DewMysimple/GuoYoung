# ADR-003 存储键恒为 `site-hub:v1`，版本写入 state 内部并逐级迁移

[[Wiki/决策/MOC_决策|← 返回决策 MOC]]

## 背景

存储结构随版本从 v1 演进到 v8。若更换存储键或破坏旧数据，会导致用户收藏丢失、升级后白屏。

## 决策

- 持久化存储键**永远为 `site-hub:v1`**，不随版本更换。
- 数据版本号写入 state 内部字段（非键名）；读取时按 `storage.ts` 逐级从 v1 迁移到当前版本。
- 迁移铁律：**只补默认字段、绝不覆盖用户已有收藏**；解析失败时不覆盖损坏的源值，仅回退到安全默认值。

## 影响

- 新增 state 字段必须写迁移分支，且默认值是安全占位而非覆盖。
- `storage.ts` 是迁移唯一入口，改动需配套回归测试。
- 与所有功能添加日志（v3/v5/v6/v7/v8）强相关。
