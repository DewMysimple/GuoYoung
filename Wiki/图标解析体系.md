# 图标解析体系

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 图标解析集中在 `src/components/favicon.tsx` 与 `src/lib/site-utils.ts`，平台缓存 URL 和占位图校验分别在 browser-runtime 与 browser-favicon-placeholder。以下按 1.1.78 源码核对，历史日志中的“七级/LRU”不能代替当前行为。

## 按平台生成候选

- 用户显式来源（含自定义 URL）排在自动候选之前，URL 去重；显式选择内置品牌且有匹配图标时直接展示品牌。
- 扩展可用浏览器 favicon 接口时：已知官方原生图标 → 根 favicon.ico → 浏览器精确页面/站点根缓存 → DuckDuckGo → Google。
- 普通网页：已知官方原生图标 → 根 favicon.ico → Google → DuckDuckGo。
- 候选耗尽后，有内置品牌则显示品牌；无品牌且有低清候选则采用其中最高分辨率项，否则显示名称/域名字母。没有额外的“第七级默认图标”。

## 64px 门槛与 bestLowResolution

- Google 请求使用 `sz=256`；浏览器 favicon 接口请求 64px，其他来源尺寸由资源决定。
- `<64px` 的源图标只记为**低清候选**，不参与优先回退（见 [[Wiki/决策/ADR-014|ADR-014]]）。
- `bestLowResolution` 暂存门槛以下的最佳候选，仅在没有品牌及高清图标时兜底。用户自定义、显式来源及无法取得尺寸的结果不受自动 64px 门槛限制。

## 占位图指纹验证

- 浏览器（尤其 Chrome）对无 favicon 站点返回通用占位图（`_favicon` 类）。该占位图跨浏览器/跨站点高度相似，会制造"图标都一样"的假象。
- 仅自动来源中的浏览器 favicon 进行占位图校验；命中或校验失败则尝试下一候选，旧异步结果不得影响已切换的来源（见 [[Wiki/日志/Bug处理/第004次|Bug处理·第004次]]、[[Wiki/日志/工程讨论/第001次|工程讨论·第001次]]）。

## 有界缓存（256）

- 页面级 Map 保存最终图像/品牌/字母结果，容量 256；新增键超限时淘汰最早插入项。读取不刷新顺序，因此不是 LRU。
- 缓存键包含来源标识和完整候选列表；来源或 URL 变化会重新初始化解析状态。

## SiteIconSource 七态

- 持久化枚举为 `auto / browser / google / root / duckduckgo / brand / custom`，用于来源选择与解析；字母是最终显示结果，不是独立来源枚举。
- 状态 v7 引入**浏览器图标缓存**，命中来源直接复用，减少回源（见 [[Wiki/日志/功能添加/第011次|功能添加·第011次]]）。

## 首字层移除规则

- 字母占位图在某些版本作为"首字层"叠加在卡片上；切换分组时曾出现首字层残留/叠加（见 [[Wiki/日志/Bug处理/第002次|Bug处理·第002次]]）。
- 规则：图标加载完成即移除首字层；分组切换不保留上一站点的首字层。

## 硬编码站点白名单

- 少量站点官方图标路径稳定但自动探测易失败，维护已知原生图标路径表；路径表变更须同步候选顺序与测试。
