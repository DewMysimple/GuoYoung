# 图标解析体系

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

> 图标解析集中在 `src/components/favicon.tsx` 与 `src/lib/site-utils.ts`。任何改动须同步七级回退链与占位图指纹。

## 七级回退链

1. 用户自定义图标地址（最高优先）。
2. 每站点"图标来源"显式选择（见 [[Wiki/日志/功能添加/第008次|功能添加·第008次]]）。
3. 站点根目录 `/favicon.ico` / `icon` 链接。
4. 国内可直连图标源（优先，避免墙内失败）。
5. Google `s2/favicons` 兜底。
6. 按域名/名称稳定生成的字母占位图。
7. 最终兜底默认图标。

## 64px 门槛与 bestLowResolution

- 请求图标时 `sz=256` 获取高清版本。
- `<64px` 的源图标只记为**低清候选**，不参与优先回退（见 [[Wiki/决策/ADR-004|ADR-004]]）。
- `bestLowResolution` 在候选集中挑选满足清晰度门槛的最佳项。

## 占位图指纹验证

- 浏览器（尤其 Chrome）对无 favicon 站点返回通用占位图（`_favicon` 类）。该占位图跨浏览器/跨站点高度相似，会制造"图标都一样"的假象。
- 每个候选图标计算**占位图指纹**；命中指纹则判死，跳到下一回退级（见 [[Wiki/日志/Bug处理/第004次|Bug处理·第004次]]、[[Wiki/日志/工程讨论/第001次|工程讨论·第001次]]）。

## LRU 缓存（256）

- 解析结果与最终图标 URL 进入容量 256 的 LRU 缓存，避免重复网络请求与抖动。
- 缓存键含来源标识，区分"用户自定义 / 自动解析"。

## SiteIconSource 七态

- 每站点记录图标来源七态（无 / 自定义 / 根 favicon / 国内源 / Google / 字母图 / 默认），用于回退与设置面板展示。
- 状态 v7 引入**浏览器图标缓存**，命中来源直接复用，减少回源（见 [[Wiki/日志/功能添加/第011次|功能添加·第011次]]）。

## 首字层移除规则

- 字母占位图在某些版本作为"首字层"叠加在卡片上；切换分组时曾出现首字层残留/叠加（见 [[Wiki/日志/Bug处理/第002次|Bug处理·第002次]]）。
- 规则：图标加载完成即移除首字层；分组切换不保留上一站点的首字层。

## 硬编码站点白名单

- 少量站点官方图标路径稳定但自动探测易失败，维护硬编码白名单直连；白名单变更须同步回退链与测试。
