# 系统架构

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

## 技术栈

- React 19 + TypeScript + Vite 7 + Tailwind v4（Vite 插件形式，无独立 config）。
- 拖拽：`@dnd-kit/core` + `@dnd-kit/sortable` + `@dnd-kit/utilities`。
- 动效：`framer-motion` 精确锁 `12.23.12`（见 [[Wiki/决策/ADR-010|ADR-010]]）。
- 图标：`@phosphor-icons/react` + `simple-icons`。
- 测试：vitest（单元）+ @playwright/test（E2E）。

## 模块组成（已核实行数）

- `src/App.tsx`（1821 行）— 网页版主应用与布局编排。
- `src/components/settings-panel.tsx`（1453 行）— 设置面板（五分类页签、高级微调）。
- `src/styles.css`（3558 行）— 全局样式与设计令牌。
- `src/lib/storage.ts`（654 行）— 存储键 `site-hub:v1` 与 v1→v8 逐级迁移（见 [[Wiki/数据与存储契约|数据与存储契约]]）。
- `src/components/popup-app.tsx`（480 行）— 扩展 popup 双页签。
- `src/lib/site-utils.ts`（410 行）— 站点解析、图标 URL 构造。
- `src/lib/use-site-hub.ts`（361 行）— 自研状态 hook（唯一全局状态源）。
- `src/components/favicon.tsx`（261 行）— 图标解析与回退（见 [[Wiki/图标解析体系|图标解析体系]]）。
- `src/components/` 共 13 个组件；`src/lib/` 共 14 个非测试模块；14 个 `.test.ts(x)` 单测文件。

## 无状态库约定

- 全局状态集中在 `use-site-hub.ts` 单一自研 hook，**不引入 Redux / Zustand**（见 [[Wiki/决策/ADR-001|ADR-001]]）。
- 所有跨组件状态读写经该 hook；新增 state 字段必须配套迁移（见 [[Wiki/数据与存储契约|数据与存储契约]] 迁移铁律）。
- 排序位移只允许 dnd-kit 控制，禁止在排序元素叠加 Motion transform（见 [[Wiki/拖拽交互契约|拖拽交互契约]]）。

## 设计约束

- 双模式构建：同一源码 `vite build` 与 `vite build --mode extension` 区分产物（见 [[Wiki/决策/ADR-002|ADR-002]]）。
- 存储键永不更换（`site-hub:v1`），仅 state 内部写版本号（见 [[Wiki/决策/ADR-003|ADR-003]]）。
- 端口：开发与 `start-site-hub.vbs` 用 5173；Playwright 用 4173，两套互不冲突。
