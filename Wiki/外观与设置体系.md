# 外观与设置体系

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

## 侧栏形态

- 采用 **Notion 式非阻塞侧栏**：侧栏从右侧滑入，不遮挡主内容，提供无左侧阴影的细边界与常驻短拖动柄，支持整卡点击实时预览（见 [[Wiki/日志/功能添加/第007次|功能添加·第007次]]）。
- 侧栏内编辑即时反映到主区，无需保存即预览。
- 1.1.85 设置右上角只保留关闭，不再提供重复的“返回”；关闭仍取消当前草稿。其他编辑/管理弹窗的返回入口保持原契约。

## 预览与保存分离

- 设置面板内修改即时预览，但**显式保存**才写入 `site-hub:v1`；取消则丢弃本次会话的预览态。
- 打开侧栏时保存初始草稿快照。点击侧栏外区域时，无改动直接关闭；有未保存修改则以透明遮罩确认“继续编辑”或“放弃更改”，放弃后清除即时预览并恢复已保存设置。外部关闭层拦截本次点击，不允许穿透后顺带打开网站或切换分组。
- 壁纸“在页面拖动调整”期间不挂载外部关闭层，页面继续接收拖动、滚轮缩放和键盘微调；退出该模式后恢复普通外部关闭语义。
- 品牌和壁纸各自使用图片操作会话；换源、新任务、关闭/保存或卸载都会使旧任务失效，旧结果与错误不得覆盖当前草稿。图像解码与 IDB 失败路径也必须释放资源；组件卸载后的本地壁纸读取结果不能再创建 object URL。
- 壁纸、搜索历史等 state 字段按版本迁移（见 [[Wiki/数据与存储契约|数据与存储契约]]）。

## 外观个性化入口

- 外观页按“主题 → 页面布局 → 界面尺寸 → 主题色与文字大小 → 名称与图标”组织，默认不展示数值滑杆。布局提供紧凑、标准、宽松三张示意卡，颜色保留六个常用色与自定义取色器。
- “布局微调”默认收起，提供页面宽度、卡片宽度、卡片高度、卡片间距、卡片圆角五项；高度沿用既有 cardHeight（112–240px）。原五分类的 27 项独立调节继续移除，现行入口见 [[Wiki/决策/ADR-016|ADR-016]]。
- 微调的“恢复默认”只恢复布局几何；“恢复上次预设”回到本次最近选择的布局，尚未选预设时恢复打开设置前的布局，跨设置页签仍保留该快照。二者保留主题色、字号和品牌内容，保存前都可取消。
- “界面尺寸”独立折叠，提供顶栏高度（48–96px）和设置侧栏宽度（360–760px，随可用空间缩小）。桌面端可直接拖动边界，支持方向键、Home/End 和双击默认；失焦、隐藏、指针取消或 Esc 回到拖动开始值。顶栏在设置内修改走草稿保存/取消，设置外拖动松手后保存；侧栏宽度沿用本地偏好自动记忆。窄屏继续使用安全几何。
- 文字大小为较小（95%）、标准（100%）、较大（110%）。布局预设只调整几何，切换布局保留字号、主题色和品牌几何；显式选择字号时统一四类文字比例，避免旧版全局和局部倍率叠乘。
- 预设高亮从真实几何值推导；手动微调后显示“已自定义”，调回预设数值时重新高亮对应方案。旧版局部字号不匹配新方案时显示“保留自定义字号”，不伪装成标准。
- 名称与图标采用独立折叠卡片，保留名称、显示开关、本地图片、网络地址与品牌重置；品牌校验错误会展开对应输入区。品牌重置会取消尚未完成的图片任务，防止旧结果重新覆盖默认品牌。
- 自定义取色器在卡片内展开并参与滚动，不遮挡文字选项，也不越出侧栏或被固定保存栏截断。
- “恢复默认外观”恢复全部外观参数，包括主题（跟随系统）与旧版隐藏参数；保留品牌内容、壁纸与收藏。仍需保存才落库，取消可撤销本次恢复。

## 兼容与模块边界

- state 为 v18，存储键仍为 `site-hub:v1`；主题写入 `appearance.theme`，玻璃材质写入 `wallpaper`，迁移只补缺失偏好。旧版保存的几何和字号继续读取、渲染与导出，打开设置、修改颜色或保存不会清除隐藏值。
- `settings-panel.tsx` 持有一份草稿及保存/取消、图片与壁纸定位会话；`components/appearance-settings.tsx` 和 `brand-settings-editor.tsx` 是受控编辑视图，不另建外观状态源。
- `lib/appearance-settings.ts` 统一布局/字号选项、五项微调定义及预设匹配/纯变换；`data/defaults.ts` 保存几何预设，`components/appearance-settings.css` 保存新界面的局部样式。旧五分类数据表、分支与样式已移除。
- 颜色仍统一由主题强调色派生，不逐项开放元素配色。

## 明暗主题（1.1.83）

- “主题”位于外观首张卡片，1.1.84 改为“跟随系统 / 浅色 / 深色”三张选择卡，与页面布局共用 `appearance-option-grid` 的网格、边界和选中态。每张卡片提供明暗示意、图标、名称和简短说明，整卡点击与键盘激活继续使用原受控按钮。
- 主题示意图使用局部静态明暗样本，不随当前主题整体变色；跟随系统显示左右明暗两半。实际选择高亮只由 appearance.theme 推导，未增加第二份主题状态或独立保存入口。
- 偏好属于同一份 AppearanceSettings 和设置草稿：即时预览，保存才写库，取消或关闭恢复已保存方案；修改主题也参与未保存判定。布局预设、字号和壁纸不覆盖主题，恢复默认外观将主题重置为跟随系统。
- 新安装默认跟随系统；v15 及更早数据缺少该字段时保留原浅色，有效偏好只保留不覆盖。非法 v16 偏好规范化为 system，详见 [[Wiki/数据与存储契约|数据与存储契约]]。
- useTheme 在 layout effect 内设置根节点 data-theme、原生 color-scheme 和浏览器 theme-color，仅 system 订阅系统颜色变化；切到固定方案或卸载时解除订阅。实际系统颜色只是派生显示，不作为第二份设置持久化。
- `src/theme.css` 共用浅/深两套表面、文字、边界、强调色文字、危险/警告/成功提示与壁纸变量；主页面、body Portal、历史/GitHub、设置和 popup 使用同一颜色契约。popup 打开读取共享收藏设置，保留其独立窗口尺寸。
- 深色使用灰蓝底与分层表面，自定义主题色继续控制按钮，强调文字适度提亮；危险文字与危险实底分别取色，白色勾选在两种主题保持清晰。壁纸遮罩、文字阴影和小标签边界随主题变化，保持此前轻透与原外形要求。
- 已加载的网站图标与内置品牌图标使用小面积中性浅色底，避免 GitHub 等透明黑色图标沉入深色表面；图像本身不反色，加载占位继续使用当前主题。

## 壁纸与数据编辑

- 1.1.90 增加六套玻璃预设：液态清透、水晶棱镜、柔光薄雾、细腻磨砂、轻透无影、经典玻璃。预设只修改现有十个玻璃字段；图片、构图、遮罩和顶栏均保留，沿用预览/取消/保存边界，不保存额外 presetId。高亮由实际参数匹配，微调后显示“已自定义”。旧偏好与默认经典玻璃不被升级覆盖。
- 壁纸的位置与构图、阅读与氛围、玻璃外观、顶栏外观默认折叠；玻璃预设在外观组内，十项微调继续单独折叠。原生 details/summary 统一为 SettingsDisclosure，收起保留草稿并支持键盘；图片来源入口仍直接可用。其他页面既有布局微调/界面尺寸/品牌/回收站参数折叠保持。
- 折射由圆角凸透镜的入射/折射方向推导，仅作用于背景；三个共享滤镜分别测量卡片、GitHub 长条入口、搜索框尺寸，一个 ResizeObserver 更新尺寸，MutationObserver 只在可见代表节点更换时重新绑定。无需逐卡观察、逐帧动画或背景截图副本，圆角微调会重算贴图。feImage 使用测得的数值宽高，避免零尺寸 SVG 的百分比解析把背景整体偏移；生产像素对照要求中心不变、边缘有变化。高光使用方向不同的内缘反光，投影仍可归零。
- 删除收藏网格和共享搜索框挂载时的 opacity 渐显（搜索框同时去掉 16px 上移动画）：小于 1 的祖先透明度会形成 backdrop root，导致从历史返回 GitHub 时先失去背景滤镜、动画结束后才恢复。工作区内容现在直接以最终材质显示，玻璃和 Portal 参数在 layout effect、首帧绘制前同步。
- 启动在 head 阶段并行读取扩展权威存储，等待数据完成后首次挂载 React；读取期间接住 chrome.storage.onChanged，读取失败保持 recovered 保护。移除中央加载动画，保留屏幕阅读器读取状态；已保存壁纸和主题预先绘制，再连续交给应用。缓存从 1920px / WebP 0.82 开始，预算 800000 字符；慢网络/首次无缓存仍受实际 I/O 限制，不宣称零耗时，未增加收藏 HTML/历史副本。
- 液态效果参考 [kube.io 的 CSS/SVG 光学推导](https://kube.io/blog/liquid-glass-css-svg/)、[rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 与 [MDN 背景采样边界](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)。未复制第三方组件或引入运行依赖；Chromium 使用背景位移，其他引擎与减少透明度偏好保留降级。

- 1.1.89 将卡片、普通按钮、菜单与面板分层：玻璃透明度仍控制卡片，新增按钮透明度（默认 82%）、面板透明度（60%）、菜单透明度（55%）和阴影强度（35%，0 关闭投影）。全部范围为 0–100，仍共用壁纸草稿，预览/取消/保存/恢复玻璃默认走同一边界；强调色实底按钮保留可读性配色。
- 材质公式、边缘与三级投影集中到 wallpaper-glass.css；theme.css 只提供随主题变化的表面色、阴影色和文字色。移除 grouped-collection.css 的旧玻璃覆盖及不存在的 glass-border 引用，去掉重复玻璃默认值和叠加填色。分类标签仅用内高光，避免滚动容器裁出灰色横带；搜索、卡片、菜单不再叠加第二层投影。
- 卡片编辑、删除和拖动按钮沿用卡片材质，仅悬停/聚焦时有轻底色，删除确认保留危险色；尺寸、焦点、传感器与 dnd-kit 位移不变。设置抽屉无外投影，管理器两栏、设置卡片和控件使用轻量半透明内层，不加重复模糊。
- 任意壁纸与透明度组合不保证自动对比度：深色主题配浅壁纸时可提高既有明暗遮罩；界面提供说明，不暗中修改遮罩或用户保存的透明度。
- 页脚本地保存说明保持与卡片左边缘对齐的普通文字，取消贴字玻璃底板、背景模糊、投影和文字阴影。

- 1.1.88 补齐 GitHub 官方入口：卡片伪元素读取共享玻璃/折射变量，父节点不形成 backdrop 根，三点菜单可以继续采样后面的壁纸；图标底座、刷新按钮、展开态和菜单同步材质，保留无壁纸实色外观。
- 启动采用已保存壁纸的小尺寸预览：head 中的独立 wallpaper-boot.js 在应用模块前绘制，构图、模糊、遮罩及主题与保存值一致；React 先接管同图预览，再显示已加载的原图。原生细滚动条从预览阶段就启用，避免加载中重新露出左白边。
- 未缓存时先等待图片，不提前展示实色收藏网格；4 秒兜底解除等待，迟到的图片仍可接管，已有预览遇到原图失败继续显示。旧版首次升级会自动生成缓存；网络图片只有允许跨域读取时才能生成预览，不保证首次联网即出图。草稿不更新启动缓存，保存清除后移除缓存。

- 壁纸页由 wallpaper-settings-editor 受控展示图片来源/缩略预览、位置与构图、阅读与氛围、玻璃外观、顶栏外观五张卡片；本地图片和网络地址均保留，填充方式以源码的铺满（cover）与完整显示（contain）为准，不提供平铺。所有参数继续写同一 WallpaperSettings。
- 清晰阅读、柔和背景、突出壁纸三个快捷方案只改壁纸模糊/遮罩，保留独立玻璃和顶栏参数。图片导入代次、IDB 和取消保护继续由设置容器负责，视图不另建草稿。
- 1.1.87 公开玻璃透明度（0–100%，越高越透明，默认 78%）、磨砂（0–30px，默认 12px）、饱和度（100–200%，默认 130%）、高光（0–100%，默认 45%）、卡片折射开关（默认关）及强度（0–40px，默认 24px）。滑杆即时预览，保存才落库，取消和清除壁纸的未保存操作均可回滚；恢复玻璃默认重置玻璃字段（v18 起包括四项分层/阴影参数），保留图片、构图和顶栏。
- 顶栏默认“融入壁纸”，不绘制通栏底板；可切换“玻璃底板”，独立控制透明度、模糊开关与模糊强度。内部 topbarOpacity 继续保存不透明度，UI 显示其反值，避免破坏旧数据；玻璃伪元素实际读取顶栏变量，修复上一版共享样式覆盖调节的问题。
- 1.1.87 最初采用单个共享 SVG 位移滤镜，1.1.90 已升级为上文按形状测量的三个共享滤镜；卡片使用 backdrop-filter 弯折背景，文字与拖拽 transform 不参与。保守地仅为 Chromium 启用 SVG 管线，其余浏览器保留磨砂，系统减少透明度时关闭背景滤镜。参考 [rdev/liquid-glass-react](https://github.com/rdev/liquid-glass-react) 与 [LeonardSEO/liquid-glass-react](https://github.com/LeonardSEO/liquid-glass-react) 的背景位移思路，未引入第三方运行依赖或复制其组件。
- 壁纸下保持原有页面几何与轮廓，导航、搜索、分类标签、管理/排列控件、收藏卡片、分组操作、菜单、设置与编辑弹层都采用玻璃材质；标题、分组标题和页脚仍按文字层级显示，不铺整条底板，也不把类别说明等文字行包成卡片。收藏、GitHub 和浏览历史共享同一效果；无壁纸时保持原实色主题。
- 历史版本 1.1.86 的共享样式位于 `wallpaper-glass.css`，当时主题参数集中在 `theme.css` 的 `--glass-*` 变量；1.1.89 已收敛为上文单一材质公式。浅色使用 24px 模糊、160% 饱和度，深色使用 26px 模糊、150% 饱和度；可交互表面保留半透填色、边缘反光、内侧亮线和分层投影。复核设置抽屉后将大面板填色调至浅色 58%、深色 67%，降低过实感；菜单、按钮和卡片分别使用独立透光层级，保障长内容可读性并让壁纸能透入大面板。
- 组件保留尺寸、圆角、拖拽阈值和交互态，不新增第二套设置。1.1.86 当时无存储新增，1.1.87 参数经 v17 补齐；卡片常态只叠加单次填色和轻高光，避免多层填色削弱透明度。生产 CSS 使用变量引用保留标准 `backdrop-filter`；顶栏磨砂绘制在独立伪元素上，使其弹出菜单继续采样壁纸。`prefers-reduced-transparency` 下改用高不透明底色，浏览器不支持标准 `backdrop-filter` 时回退到实色表面。
- 材质原则参考 [Apple Human Interface Guidelines: Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的内容透显与层级透明度建议；背景滤镜层叠边界按 [MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter) 核对。
- 数据页由 data-settings-editor 展示收藏概况、备份、最近搜索、回收站和恢复默认；回收站确认计时与展开状态归该组件持有。备份明确不含回收站、搜索历史及本地壁纸文件；数据操作仍调用原业务命令，不纳入外观草稿。

## ≥900px 响应式安全几何

- 桌面端以 **≥900px** 为响应式安全几何下限；低于该宽度仅做必要降级，不破坏几何比例。
- 顶栏以自身 inline-size 容器宽度判断紧凑导航，≤700px 可用空间时隐藏按钮文字并保留图标和可访问名称；900–1100px 窗口打开设置侧栏同样适用，按钮不换行、不互相压缩。
- 分组标题操作收进同一行，图标、卡片与页面标题共用左边缘；插入/选择控件保持在视口内。
- 手机端保持双列布局，避免卡片过窄（见 [[Wiki/日志/UI修改/第001次|UI修改·第001次]]）。

## 编辑弹窗的外壳与滚动

- 无壁纸时根页面沿用 1.1.85 的 scrollbar-gutter: stable both-edges。1.1.87 壁纸模式取消左侧根预留，右侧使用 stable + 持续显示的原生细滚动条；在壁纸覆盖范围内以实测滚动条宽度补左内边距，去除左白边并维持搜索居中。不能用根背景图片填补 gutter，也不能假设 100vw 减 100% 恒等于滚动条宽度。侧栏、分组管理列表/编辑区、回收站、网站/新组/仓库弹窗内部滚动区以及 popup 书签树仍使用 stable。不要对横向分组标签滚动区套用垂直预留策略。
- Windows 经典滚动条必须单独验证：Playwright 默认的 --hide-scrollbars 会掩盖内容被挤窄的问题。scroll-stability.spec.ts 显式取消该参数，覆盖设置折叠跨越溢出临界点、页面短/长切换与模态滚动锁；overlay 滚动条设备不产生多余预留宽度。

- 添加网站、管理分组、新建分组及删除确认统一采用**透明页面遮罩 + 不透明固定圆角外壳**；任何弹窗都不暗化或模糊页面，但遮罩仍阻止背景误操作。
- 居中式弹窗外壳必须有完整、对称的四角圆角，固定高度并设置 `overflow: hidden`；外层不得承担滚动，内容超高时只允许中间内容区滚动，标题与底部操作固定。禁止滚动条贴边造成单侧圆角、直角、截断、缺角、背景断面或外壳不完整；任何此类现象均视为 UI 回归，提交前必须用真实浏览器截图复核。
- 仓库导入、编辑网站、管理分组、新建分组及确认弹窗都必须遵守同一外壳规则：内层滚动容器要在外壳圆角裁剪范围内，滚动条不能覆盖外壳边界，也不得通过内容溢出破坏四角。移动端保留约 12px 页面边距和卡片式圆角，不降级为贴边全屏。
- 设置侧栏是明确的右侧贴边抽屉，可保留贴边边缘；但其滚动、裁剪或子元素仍不得制造意外缺角、单侧直角或视觉断面。
- Radix 模态滚动锁定时，页面滚动容器已经承担滚动条宽度；不得再向 `body` 叠加相同的右侧补偿，否则打开编辑网站或管理分组会让居中的工作区向左跳动。锁定期间保持工作区水平几何不变，同时继续保留焦点陷阱和背景拦截。
- 管理分组提供 48 个统一 Phosphor 语义图标；桌面端保持 6 列，图标较多时由右侧编辑区独立滚动，窄屏降为 4 列并复用弹窗内容滚动，避免弹窗整体高度失控。
- 删除分组属于当前分组的一级操作，固定在分组摘要行，不放到编辑面板末尾。
- 单组删除在摘要行二次点击确认；管理器批量删除使用确认弹窗。分组标题插入加号在正常浏览时常驻，与三点操作共用紧凑控件；选择模式替换为圆形选择，排序期间禁用。锚定菜单支持当前组前后插入，“其他”只允许前插。

- 网站、管理分组、新建分组和仓库导入的返回/关闭按钮共用 DialogNavigation；网站草稿按目标 ID 初始化，外部分组列表更新只修正失效目的组，不重置未保存输入。
- 设置－数据包含可展开的链接回收站：展示站点、域名、原分组、删除时间与剩余天数，提供逐项/全部恢复、逐项永久删除、清空及 7/30/90 天或永不自动清理期限。普通操作提示统一在 5 秒后自动关闭，恢复横幅和表单错误保持持久。

## 历史面板与收藏卡片一致性

- 收藏主页、GitHub 与历史搜索共用 WorkspaceSearch 的实际结构、输入/清空及 Motion 入场效果；收藏保留搜索引擎提交和最近搜索插槽，历史保持独立查询边界。历史搜索在主内容顶部使用同一 `workspace-intro`，不得在上方插入大标题或额外顶部内边距；数量、范围与多选归入搜索下方工具栏。
- 收藏、GitHub、历史总览和历史详情共用 CardSurface / CardContent / CardOpenAction / CardSelectionToggle；打开、选择、禁用处理统一，选择态使用按钮避免误打开链接，数据与拖拽策略仍由各自工作区持有。历史站点卡片与 URL 详情卡片复用 `site-card`、`site-card-topline`、`site-card-link`、`site-name`、`site-domain` 与 `site-category`。只由外层卡片承担内边距、最小高度、圆角与表面；内层不得再次叠加同一几何参数。
- 底部用单行短日期显示最近访问，完整日期、访问次数通过整卡提示提供，站点详情摘要保留访问总数；选择模式底部为右下角圆形选择控件预留空间。桌面与移动端均比较主页/历史实际卡片宽高及搜索框位置。
- 历史时间范围使用带顶栏历史记录图标的中等圆角控件，默认选择“近 7 天”；标签与选项文字保持清晰的 12/13px 层级；详情页返回按钮与浏览器原生后退共享同一层级状态，返回列表时恢复原滚动位置。设置、分组管理、添加/编辑和 GitHub 导入面板的标题栏统一提供“返回”与关闭按钮。

## 品牌标识

- 品牌名 `Mysimple · 网站收藏`；搜索框居中、垂直节奏由设计参数控制（见 [[Wiki/日志/UI修改/第002次|UI修改·第002次]]）。
- 顶部品牌是无 `href` 的按钮：点击只在当前应用内回到收藏主页，不改变 URL、不打开空白页面；收藏主页、GitHub 与历史记录仍由各自的顶栏入口负责切换。

## 边界手柄悬停反馈（1.1.82）

- 面板边界手柄参考 WhisperSubtitle 的 `apps/web/src/styles.css`：竖向线 54→72px、横向线 64→96px，hover / focus-visible / 拖动中均展开，160ms 过渡，4px 轻微主题色光晕。默认低对比度细线，移开收回；居中展开不推动面板内容，横向命中区覆盖展开长度。共用 `resize-handle.css`，保留原拖动/取消/键盘逻辑，减少动态效果偏好下不播放过渡；899px 以下仍隐藏桌面直接拖动柄。
