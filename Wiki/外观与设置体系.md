# 外观与设置体系

[[Wiki/MOC_项目知识|← 返回项目知识 MOC]]

## 侧栏形态

- 采用 **Notion 式非阻塞侧栏**：侧栏从右侧滑入，不遮挡主内容，支持整卡点击实时预览（见 [[Wiki/日志/功能添加/第007次|功能添加·第007次]]）。
- 侧栏内编辑即时反映到主区，无需保存即预览。

## 预览与保存分离

- 设置面板内修改即时预览，但**显式保存**才写入 `site-hub:v1`；取消则丢弃本次会话的预览态。
- 打开侧栏时保存初始草稿快照。点击侧栏外区域时，无改动直接关闭；有未保存修改则以透明遮罩确认“继续编辑”或“放弃更改”，放弃后清除即时预览并恢复已保存设置。外部关闭层拦截本次点击，不允许穿透后顺带打开网站或切换分组。
- 壁纸“在页面拖动调整”期间不挂载外部关闭层，页面继续接收拖动、滚轮缩放和键盘微调；退出该模式后恢复普通外部关闭语义。
- 壁纸、搜索历史等 state 字段按版本迁移（见 [[Wiki/数据与存储契约|数据与存储契约]]）。

## 高级微调五分类

- state v8 引入高级微调**五分类页签**（见 [[Wiki/日志/功能添加/第012次|功能添加·第012次]]）：布局 / 卡片 / 文字 / 壁纸 / 品牌。
- 只开放**几何参数**：尺寸、间距、圆角、比例、密度（见 [[Wiki/决策/ADR-009|ADR-009]]）。

## 只几何不颜色

- 颜色统一由**主题色**（强调色 / 背景 / 文本）管理，高级微调**不逐项开放元素配色**，避免退化为简陋主题编辑器。

## 图像三类独立参数

- 壁纸按"填充 / 平铺 / 居中"三类各自独立参数（state v6），互不干扰（见 [[Wiki/日志/功能添加/第009次|功能添加·第009次]]）。
- 排列筛选、HSV 取色器在 v6 落地。

## ≥900px 响应式安全几何

- 桌面端以 **≥900px** 为响应式安全几何下限；低于该宽度仅做必要降级，不破坏几何比例。
- 手机端保持双列布局，避免卡片过窄（见 [[Wiki/日志/UI修改/第001次|UI修改·第001次]]）。

## 编辑弹窗的外壳与滚动

- 添加网站、管理分组、新建分组及删除确认统一采用**透明页面遮罩 + 不透明固定圆角外壳**；任何弹窗都不暗化或模糊页面，但遮罩仍阻止背景误操作。
- 弹窗最外层必须 `overflow: hidden` 以保护四角和阴影；内容超高时只允许中间内容区滚动，标题与底部操作固定，禁止把原生滚动条挂在弹窗外壳上。
- 管理分组在桌面端以 6×4 完整展示 24 个图标，不为图标网格建立独立滚动区；窄屏降为 4 列并复用弹窗唯一内容滚动。
- 删除分组属于当前分组的一级操作，固定在分组摘要行，不放到编辑面板末尾。
- 分组删除的最终处理方案使用 2 秒内二次点击确认；“全部－按分组显示”不再创建独立组间行，每个分组标题在内容边界左侧以绝对定位提供仅含“+”的 24px 圆形入口，不占据标题布局，因此分组图标与卡片左缘保持对齐。入口使用实体表面底色、细边框和分层轻阴影；其外侧容器默认参与指针命中，桌面指针直接进入按钮所在区域即可揭示，无需先悬停分组标题；触屏常驻。分组排序期间该命中区关闭，避免干扰拖拽。锚定菜单选择在当前组前后插入，“其他”只允许前插。

## 设计参数与网格

- 主内容最大宽度 **1600px**，主容器/导航/分组栏/页脚统一限宽（见 [[Wiki/日志/UI修改/第001次|UI修改·第001次]]）。
- 网格用 `auto-fill` 自适应列，弃用 `100vw`（见 [[Wiki/决策/ADR-006|ADR-006]]、[[Wiki/日志/Bug处理/第005次|Bug处理·第005次]]）。
- 字号作用域扩张至 Logo 与卡片相对比例（state 后续轮次，见 [[Wiki/日志/功能添加/第010次|功能添加·第010次]]）。

## 品牌标识

- 品牌名 `Mysimple · 网站收藏`；搜索框居中、垂直节奏由设计参数控制（见 [[Wiki/日志/UI修改/第002次|UI修改·第002次]]）。
